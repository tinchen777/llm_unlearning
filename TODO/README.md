# TODO 目录约定

- 每条"线"（line）一个文件夹：近期有两条，二者最终会汇合：
  - `near_line/`：优化 NEAR 方法本身（遗忘效果 + 保持 retain）
  - `metric_line/`："遗忘可检测度"指标（攻击者能否发现模型被遗忘过）
- 每次进展写成一个 md 文件：`<序号>_<主题>.md`，内容固定为：问题 / 做法 / 结果 / 下一步。
- "下一步"怎么解决、结果如何，写在下一个 md 文件 里（序号 +1）。
- 想知道某条线推进到哪了：读该文件夹里序号最大的 md 的"下一步"。
- 其它：保持简短，只写关键点；数字以 `saves/` 里的文件为准（路径写在文件里）。
