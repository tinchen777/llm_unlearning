# A2 影子模型白盒探针攻击（Shadow-Probe Attack, SPA）规格说明

> 2026-11-12。对应摘要中的承诺："A black-box ranking attack and an adaptive white-box attack further show that these traces can be exploited to identify forgotten entities under existing methods."
> 论文位置：§3.4（定义）、§10（结果）。实现时如偏离本文档，请在 §9 记录。

---

## 1. 在论文中的作用

| # | 作用 | 对应要求 |
|---|---|---|
| R1 | 兑现摘要：在**现有方法**下识别出被遗忘实体 | LUNAR / ROCR / RMU / GA / NPO / MEOW 中至少大部分显著高于 retain 对照 |
| R2 | 对 NEAR 做**自适应**评估（攻击者知道算法） | NEAR-Dist 三个规模都要有 |
| R3 | 修补现有白盒指标的漏洞：`wb_unsup` 事后用标签选层；`wb_sup` 用真实标签且只覆盖线性探针 | 层只用影子数据选；加入非线性探针 |
| R4 | 佐证"过冲"：steering 类偏移方向共享 → 指纹可迁移；NEAR-Dist 没有共同方向 | NEAR-Act 三个规模都要有 |

## 2. 威胁模型（与 §3 的 A3 + A4 一致）

| 攻击者有 | 攻击者没有 |
|---|---|
| 被遗忘模型 M' 的权重（可前向、取激活） | 原模型 M0、retain 模型 |
| 保留数据（知道哪些作者仍在模型里，同 TAS） | provider 的遗忘集 F |
| 遗忘算法及其超参数（层、步数、系数、损失权重） | provider 的邻居（NEAR）、provider 的随机种子 |
| 生成虚构名字 / 邻居的能力（LLM） | 任何关于目标候选的标签 |

---

## 3. 数据划分（必须严格不重叠）

以 forget05 为主设置（被遗忘 10 人；holdout05 10 人；保留作者若干）。

| 集合 | 来源 | 用途 |
|---|---|---|
| **S（影子遗忘集）** | 保留作者中随机选 **5 组 × 2 人**（共 10 人），固定种子 | 影子遗忘的正例 |
| **H_A（影子陌生人）** | holdout 作者的**前一半**（5 人），可再加攻击者自造的虚构名字补足到 10 人 | 影子训练的负例 |
| **F（目标被遗忘者）** | provider 的遗忘集（forget05 的 10 人） | 攻击的正例 |
| **H_B（目标陌生人）** | holdout 作者的**后一半**（5 人）+ 自造名字补足到 10 人 | 攻击的负例 |
| **S_val / H_A_val** | S 与 H_A 中各留出 20% 作者 | 影子内测试（阳性对照） |

- H_A 与 H_B **不得重叠**；自造名字两边也不重叠。
- 自造名字：用与 TOFU 作者相同的生成方式（国籍、体裁等属性）生成，避免名字风格本身成为信号。
- 若 holdout 人数不足，优先用自造名字补齐，不要复用。

## 4. 流程

### Step 1 影子遗忘
- 对每组影子遗忘集 S_k（k = 1…5，每组 2 人），在 **M'** 上运行**同一算法、同一超参数**，得到 M''_k。
- 各方法的目标：
  | 方法 | 影子遗忘时的目标 |
  |---|---|
  | LUNAR | 原算法（拒答区域） |
  | ROCR | 原算法默认目标（与 provider 相同的名人） |
  | RMU / GA / NPO / MEOW | 原算法（MEOW 的反转事实由攻击者自己生成） |
  | NEAR-Act / NEAR-Dist | 攻击者**自己的**邻居：用 heldout 邻居（`train_rank` 11–15）充当，与 provider 的训练邻居不重叠 |
- 每组单独做（不要一次遗忘 10 人），以贴近单次删除并降低 M'' 与 M' 的偏离。

### Step 2 构造探针输入
- 问题：沿用 A1 的 **10 个通用模板**，把 `{name}` 替换为各候选名字。正负例的问题内容**完全相同，只有名字不同**。
- 激活：eoi 位置（与 `wb_unsup` / `wb_sup` 相同的 hook 点 `block_out`、相同位置定义），逐层取，位置上求平均 → 每个（名字, 模板, 层）一个向量。
- 在 M''_k 上采集：S_k 的两人（正例）与 H_A（负例）。

### Step 3 训练探针
- **主版本**：逐层 L2 正则逻辑回归（标准化在影子训练数据上拟合）。
- **非线性版本**：两层 MLP（隐藏 256，dropout 0.1，早停）。
- 训练数据：5 组 M''_k 的样本合并（每组的正例来自自己的 S_k）。
- **选层**：在影子数据上做按作者分组的交叉验证（同一作者的所有模板在同一折），选影子验证 AUC 最高的层。**不得使用 F 或 H_B 的任何信息。**

### Step 4 影子内测试（阳性对照）
- 在留出的 S_val / H_A_val 上（仍在 M''_k 上）报告作者级 AUC。
- 目的：证明探针本身有能力。没有这一项，"NEAR 下攻击失败"会被质疑为"探针太弱"。

### Step 5 迁移攻击
- 把选定层的探针用到 **M'** 上，对候选池 F ∪ H_B 的每个（名字, 模板）打分。
- 作者分数 = 该作者 10 个模板分数的平均。
- **候选池（少数派设计，与 A1 一致）**：每次取 F 中 2 人 + H_B 全部 10 人，共 C(10,2) = 45 个池；报告平均与标准差。另报一次平衡池（10 : 10）作对照。

### Step 6 阴性对照（retain 校准）
- 把 Step 1–5 整套流程跑在 **retain 模型**上（在 retain 模型上做影子遗忘，再攻击 F ∪ H_B）。
- 此时 F 与 H_B 都是 retain 没见过的人，结果应接近随机（作者级 AUC ≈ 0.5）。

## 7. 预期结果与写法

| 情形 | 预期 | 论文中的写法 |
|---|---|---|
| LUNAR / ROCR / RMU / NEAR-Act | 影子内高，迁移高 | "An adversary that only knows the algorithm learns its fingerprint on shadow entities and transfers it to the deployed model." |
| GA / NPO / MEOW | 中等 | 同上，强度较弱；结合 `wb_sup` 约 0.5 |
| NEAR-Dist，影子内高、迁移低 | 指纹存在但不迁移 | "The fingerprint does not transfer: NEAR-Dist moves each entity differently, so no shared direction exists." |
| NEAR-Dist，影子内也低 | 没有可学习的指纹 | "NEAR-Dist leaves no linearly (or MLP-) learnable fingerprint even on the attacker's own shadow model." |
| NEAR-Dist 迁移明显高于 retain | 如实报告 | 与采样、似然残留一起放入讨论 |
| retain 对照偏离 0.5 | 说明流程本身有偏差 | 先排查（名字风格、token 长度、模板），再报告 |

## 8. 容易踩的坑（实现检查清单）

- [ ] **标签泄漏**：层选择、标准化参数、阈值只用影子数据拟合。
- [ ] **H_A / H_B 不重叠**；自造名字两边不重叠。
- [ ] **两次编辑的相互作用**：检查 M''_k 上 F 的探针分数是否仍高（若第二次编辑抹掉了第一次的痕迹，迁移会被低估），在附录报告。
- [ ] **名字 token 长度**：把名字的 token 数作为协变量检查；若与分数显著相关，对长度做匹配或分层。
- [ ] **名字风格**：自造名字的国籍、性别分布与 TOFU 作者一致。
- [ ] **NEAR 的邻居**：影子遗忘用 heldout 邻居（`train_rank` 11–15），确认与 provider 的训练邻居（1–10）不重叠。
- [ ] **随机种子**：影子组划分、自造名字、探针训练都固定种子并记录。
