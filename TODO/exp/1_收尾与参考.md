## 做法（每条一张卡，互不依赖 **[并]**）
```
# 1a. forget10 的 full / retain 参考评测，只 1B（3B 选做，8B 不做）`DONE`
ONLY_SPLITS="forget10" ONLY_MODELS="Llama-3.2-1B-Instruct" SKIP_EXISTING=1 bash scripts/eval/baseline_probe.sh <GPU>
```
```
# 1b. 8B RMU 重试：lr 5e-5（2e-5 不遗忘）；需要参照模型，开梯度检查点和小批（有效批仍 8×4）`DONE`
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True EXTRA_TRAIN="trainer.args.per_device_train_batch_size=2 trainer.args.gradient_accumulation_steps=16 trainer.args.gradient_checkpointing=true" LRS="5e-5" METHODS="RMU" MODEL=Llama-3.1-8B-Instruct bash scripts/unlearn/tune.sh <GPU>
```
```
# 1c. 8B LUNAR 连续曲线：固定 l23，补 c2.2、c2.4（现有 c1–3 的选层在 l23 / l14 / l24 间跳，没有 retain 水平点） `DONE`
MODEL=Llama-3.1-8B-Instruct LAYERS="[23]" COEFFS="2.2 2.4" FORGET_SPLITS="forget01" bash scripts/LUNAR/sweep_coeff.sh <GPU>
```
```
# 1d. 8B 旧方法 c6（层 15-16-17）补评测（上次评测 OOM，这次降评测批大小） `DONE`
PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True EXTRA_WDOWN="wdown.gen_batch_size=8" EXTRA_EVAL="eval.tofu.batch_size=4" SELECT_TASK_NAME=Llama8B_v2/near_tofu_Llama-3.1-8B-Instruct_forget01_ks MODEL=Llama-3.1-8B-Instruct OUT_PREFIX=Llama8B_v2 EVAL_PROFILE=full INCLUDE_ANSWER=1 LAYER=15,16,17 COEFF=6 MULTI_LAYER=increment SEQUENTIAL=1 RETAIN_WEIGHTS="1" bash scripts/NEAR/sweep_w_down.sh <GPU>
```
