# 5 链之外还剩的实验与分析

> 更新于 2026-11-08。两条链（`scripts/exp/run_lanes.sh`）已在跑；下面是它们不覆盖的部分。❗ 必做　○ 选做。

## 1 ❗ 修正 baseline 的 lr 并重跑（依赖链的结果）
forget05、forget10 的 baseline lr 都是按步数推出来的值（未验证）。链跑完后用 `scripts/analysis/baseline_table.py` / `pareto.py` 看每个方法的 5 个 epoch 轨迹：
- 第 1 个评测点就已过冲（Prob ≈ 0、utility 崩）→ lr 减半重跑；
- 5 个点都没到 Prob ≤ 0.25 → lr 加倍重跑。
命令模板（单行，换 `LRS`、`METHODS`、`MODEL` 和划分）：
```
FORGET_SPLIT=forget05 HOLDOUT_SPLIT=holdout05 RETAIN_SPLIT=retain95 NEIGHBOR_SPLIT=neighbor05 AUTHOR_OFFSET=191 MODEL=Llama-3.2-1B-Instruct EVAL_PROFILE=full LRS="1e-5" METHODS="GradAscent" bash scripts/unlearn/tune.sh <GPU>
```
forget10 的划分：`FORGET_SPLIT=forget10 HOLDOUT_SPLIT=holdout10 RETAIN_SPLIT=retain90 NEIGHBOR_SPLIT=neighbor10 AUTHOR_OFFSET=181`。8B 的 NPO / RMU 加 `EXTRA_TRAIN="trainer.args.per_device_train_batch_size=2 trainer.args.gradient_accumulation_steps=16 trainer.args.gradient_checkpointing=true"`。
