# 7 小链 / 尾链剩余实验的并行命令（互相独立，可各占一张卡同时跑）

> 前提：两条链的**当前这一步跑完后**把链停掉（`ps aux | grep run_lanes` → `kill <pid>`，只杀链进程，不杀正在跑的那一步的子进程），再按下面开跑。下面的 baseline lr 已按 `6_*` 的结果修正（不再用链里的旧推算值）。所有命令都互相独立；`tune.sh` 不会跳过已存在的目录，开跑前先 `ls saves/tofu_unlearn/<方法>/ | grep <划分>` 确认没有同名的完成运行。
> 显存粗估：LUNAR / NEAR（1B、3B）10–20 GB；3B 的 baseline 已加梯度检查点 + 小批，约 30 GB 以上；NPO / RMU 多一份参照模型。

## A. 小链剩余：forget05 × 3B 的 LUNAR 和 baseline，以及 forget10 × 1B
```
# A1. 3B forget05 LUNAR（c1、1.5、2）
MODEL=Llama-3.2-3B-Instruct RETAIN_SPLIT=retain95 HOLDOUT_SPLIT=holdout05 EVAL_PROFILE=full COEFFS="1 1.5 2" FORGET_SPLITS="forget05" bash scripts/LUNAR/sweep_coeff.sh <GPU>
```
```
# A2. 3B forget05 baseline：GA、GD（lr 1e-5）
FORGET_SPLIT=forget05 HOLDOUT_SPLIT=holdout05 RETAIN_SPLIT=retain95 NEIGHBOR_SPLIT=neighbor05 AUTHOR_OFFSET=191 MODEL=Llama-3.2-3B-Instruct EVAL_PROFILE=full EXTRA_TRAIN="trainer.args.per_device_train_batch_size=2 trainer.args.gradient_accumulation_steps=16 trainer.args.gradient_checkpointing=true" LRS="1e-5" METHODS="GradAscent GradDiff" bash scripts/unlearn/tune.sh <GPU>
```
```
# A3. 3B forget05 baseline：NPO（2e-5）、SimNPO（1e-4）、RMU（5e-5），同一进程顺序跑
for spec in "NPO:2e-5" "SimNPO:1e-4" "RMU:5e-5"; do FORGET_SPLIT=forget05 HOLDOUT_SPLIT=holdout05 RETAIN_SPLIT=retain95 NEIGHBOR_SPLIT=neighbor05 AUTHOR_OFFSET=191 MODEL=Llama-3.2-3B-Instruct EVAL_PROFILE=full EXTRA_TRAIN="trainer.args.per_device_train_batch_size=2 trainer.args.gradient_accumulation_steps=16 trainer.args.gradient_checkpointing=true" LRS="${spec#*:}" METHODS="${spec%%:*}" bash scripts/unlearn/tune.sh <GPU>; done
```
```
# A4. 1B forget10 新方法（G_10_new 重跑，OOM 后降批；评测结果已存在则自动跳过）
FORGET_SPLIT=forget10 RETAIN_SPLIT=retain90 HOLDOUT_SPLIT=holdout10 NEIGHBOR_SPLIT=neighbor10 AUTHOR_OFFSET=181 MODEL=Llama-3.2-1B-Instruct KL_STEPS=500 EXTRA_WDOWN="wdown.kl.fr_batch_size=4 wdown.kl.batch_size=16" UPSTREAM_PREFIX=forget10_Llama1B_v2 OUT_PREFIX=forget10_Llama1B_v3 FP_WEIGHT=1 FP_TARGET=unseen FP_MODE=match KL_FORGET_W=0 KL_INIT=original KL_WEIGHTS=1 EVAL_PROFILE=full COEFFS="7" LAYER_SETS="11,12,13" bash scripts/NEAR/sweep_kl.sh <GPU>
```
```
# A5. 1B forget10 LUNAR 的 c1.5、c2（若 G_10_lunar 已经把它们跑完就不用）
RETAIN_SPLIT=retain90 HOLDOUT_SPLIT=holdout10 EVAL_PROFILE=full COEFFS="1.5 2" FORGET_SPLITS="forget10" bash scripts/LUNAR/sweep_coeff.sh <GPU>
```

## B. 尾链剩余：forget10 × 3B
```
# B1. LUNAR（c1、1.5、2）
MODEL=Llama-3.2-3B-Instruct RETAIN_SPLIT=retain90 HOLDOUT_SPLIT=holdout10 EVAL_PROFILE=full COEFFS="1 1.5 2" FORGET_SPLITS="forget10" bash scripts/LUNAR/sweep_coeff.sh <GPU>
```
```
# B2. 旧方法（forget10×3B 选层是 13，层组 11-12-13；若尾链的 I_old 已按 12-13-14 跑完，这条是修正版，目录名不同，不会覆盖）
FORGET_SPLIT=forget10 RETAIN_SPLIT=retain90 HOLDOUT_SPLIT=holdout10 NEIGHBOR_SPLIT=neighbor10 MODEL=Llama-3.2-3B-Instruct SELECT_TASK_NAME=forget10_Llama3B_v2/near_tofu_Llama-3.2-3B-Instruct_forget10_ks OUT_PREFIX=forget10_Llama3B_v2 EVAL_PROFILE=full INCLUDE_ANSWER=1 LAYER=11,12,13 COEFF=8 MULTI_LAYER=increment SEQUENTIAL=1 RETAIN_WEIGHTS=1 bash scripts/NEAR/sweep_w_down.sh <GPU>
```
```
# B3. forget10 3B baseline：GA（1e-5）和 NPO（2e-5）
for spec in "GradAscent:1e-5" "NPO:2e-5"; do FORGET_SPLIT=forget10 HOLDOUT_SPLIT=holdout10 RETAIN_SPLIT=retain90 NEIGHBOR_SPLIT=neighbor10 AUTHOR_OFFSET=181 MODEL=Llama-3.2-3B-Instruct EVAL_PROFILE=full EXTRA_TRAIN="trainer.args.per_device_train_batch_size=2 trainer.args.gradient_accumulation_steps=16 trainer.args.gradient_checkpointing=true" LRS="${spec#*:}" METHODS="${spec%%:*}" bash scripts/unlearn/tune.sh <GPU>; done
```
