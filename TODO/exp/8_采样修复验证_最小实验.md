# 8 采样层面痕迹的修复：最小验证实验（机制 → 修正 → 验证）

> 目的：用最少的实验判断“采样一致性偏低 / 替代名字集中”能不能修，从而决定论文这一部分是写成“局限”还是“机制分析 + 修正 + 验证”。所有改动默认关闭，不影响已有结果。

## 要检验的三个因素
| | 机制（证据） | 修法（新增配置） |
|---|---|---|
| (a) 名字被蒸馏 | 3B forget01 的 358 条含替代名字的回答里 51% 用训练邻居的名字，留出邻居 / retain / 旧方法为 0（`paper_notes/8` §2.3） | `kl.mask_neighbor_name`：KL 里屏蔽邻居名字的 token（`KL_MASK_NAME=1`） |
| (b) 学生拟合 10 个邻居的混合 | 同一问题的 10 次采样里平均出现 2.9 个不同的训练邻居名字 | `kl.neighbors_per_question`=m：每个遗忘问题固定 m 个邻居，按 `train_rank` 轮换（`KL_NPQ=m`） |
| (c) 逐样本概率被压到同一个值 | 遗忘集 sd(log p) 0.04–0.37，retain 0.8–1.0；mia 0.88–0.95（`near_line/25`） | `forget_prob_mode=neighbor`（逐样本目标 = 原模型对邻居答案的概率）；备选 `mean` |

## 最小设计（1B forget01 先做，6 个新训练 + 1 次采样评测）
| 变体 | 校准 | 每题邻居 | 屏蔽名字 | 检验 |
|---|---|---|---|---|
| R0 | match | 全部 10 | 否 | 现有方法（不用重训，已有运行） |
| E1 | match | 全部 | 是 | (a) 单独 |
| E2 | match | 1 | 否 | (b) 单独 |
| E3 | match | 1 | 是 | (a)+(b) |
| E4 | neighbor | 全部 | 否 | (c) 单独 |
| E5 | neighbor | 1 | 是 | 三者合并 |
| E6 | neighbor | 3 | 是 | m=1 若过度一致（比 retain 还一致）的备选点 |
前 3 个固定用 `match`，使采样指标的变化只归因于配对 / 屏蔽；(c) 单独用 E4 看 `mia_loss` 与概率分布宽度。

## 命令（一条，训练 + 评测 + 采样 + 汇总）
```
bash scripts/exp/validate_fix.sh <GPU>
```
内部对每个变体调用 `scripts/NEAR/sweep_kl.sh`（`EVAL_PROFILE=fast`），然后一次 `sample_consistency.py`（retain + R0 + 所有变体），再用 `prob_spread.py` 和 `TOFU_SUMMARY.json` 出汇总表，写到 `saves/analysis/validate_1B_f01/`（`summary.md`、`extra.txt`）。`DRY_RUN=1` 只打印命令；`SKIP_TRAIN=1` 只做采样与汇总。
只看某几个变体：`VARIANTS="E1 E3" bash scripts/exp/validate_fix.sh <GPU>`。

## 判读（决定论文怎么写）
看三个量：① 采样一致性之差（forget − holdout，retain ≈ 0，现状 −0.14 到 −0.19）；② 每题不同名字数 / 最常用名字占比 / 跨问题同名占比（retain 约 2.1–2.4 / 0.175 / 0.175，现状 6.7–6.9 / 0.24 / 0.35–0.375）；③ `mia_loss` 与 sd(log p)（retain 0.36–0.48 与 0.8–1.0）。同时看 Prob 是否还在 0.16 附近、utility、retain 生成、白盒、黑盒有没有变差。

| 结果 | 论文写法 |
|---|---|
| E1 / E2 / E3 任一把①②明显拉向 retain，且 Prob / utility / 白盒不变差 | 写成“机制分析 → 修正 → 验证”，主方法换成修好的配置（需要在 3B forget01 与 1B forget05 上确认，见下） |
| E2 的 modal_name_share 远高于 retain（过度一致） | 写成“混合 ↔ 单邻居”的两难；用 E6（m=3）作折中，并如实报告 |
| 只有 E4 把 mia 和 sd(log p) 拉回 retain | 校准目标的形状是 mia 的原因，单独写成对 `match` 的修正 |
| 全部无改善 | 保持“局限”的写法，机制证据（名字来自邻居、混合）作为观察写入分析，不声称可修 |

## 确认（只在 1B 有效时才做）
```
SETTING=3B_f01 VARIANTS="E5" bash scripts/exp/validate_fix.sh <GPU>
SETTING=1B_f05 VARIANTS="E5" bash scripts/exp/validate_fix.sh <GPU>
```
把 E5 换成 1B 上最好的变体。1B_f05 同时检验大遗忘集上的 mia 是否随校准修正而改善。
