## 三、零 GPU 的分析（D 组）

### D1 固定层白盒与 wb_sup（X5）
`wb_unsup` / `wb_sup` 取各层最大值，层是事后选的，偏乐观。`wb_fixed_layer.py` 在事先固定的相对深度（50%、75%、最后一层）报告相对 retain 模型的超额。
```
python scripts/analysis/wb_fixed_layer.py --ref saves/eval/retain/Llama-3.2-3B-Instruct/forget01 NEAR-Dist=<E8 评测目录> NEAR-Act=<Act 评测目录> LUNAR=<LUNAR 评测目录> --depths 0.5 0.75 1.0
```
已算（3B forget01）：NEAR-Act 的白盒痕迹在更深的固定层上消失，E8 在各层都接近 retain。完整表见脚本输出。

### D2 retain 上的拒答 / 编造率（X6）
已算，9 个格子里 retain 题的拒答率全是 0。holdout 上的“疑似编造”标记率为 0.20–0.34，forget 上为 0.25–0.38，full 模型为 0.00–0.07。结论：不出现过度拒答；编造率与 holdout 同量级，没有额外增加。

### D3 bootstrap 置信区间（X7）
```
python scripts/analysis/bootstrap_ci.py --n 2000 full=<full 评测目录> retain=<retain 评测目录> NEAR-Dist=<E8 评测目录> NEAR-Act=<Act 评测目录>
```
forget01 只有 40 题，区间宽且互相重叠；3B forget01 已算过，结论是 forget01 上方法之间的小差距不能当作显著，应以 forget05 / 10 为准。

### D4 E8 校准公式（X8）
对每道遗忘题 i：
- p_i = exp(真答案的平均 token 对数概率)
- τ_i = 原模型下该题的各训练邻居答案的 exp(平均 token 对数概率) 的均值
- κ = τ_unseen / mean_i(τ_i)，τ'_i = κ τ_i
- 校准损失 = mean_i (log p_i − log τ'_i)²

此为 `forget_prob_mode=neighbor_scaled`。整个过程不用 retain 模型。
