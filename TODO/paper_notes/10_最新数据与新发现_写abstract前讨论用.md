# 最新数据整理与新发现（2026-11-11，写 abstract 前与导师讨论用）

> 数据来源：`saves/analysis/main_table.md`（主表）、`pareto_grid_*`（Pareto 网格）、`wb_fixed_all.md`（E7）、`saves/eval/ROCR`、`saves/analysis/sample_*`、种子与阶梯消融的评测。**匹配规则 = forget_Q_A_Prob ≤ 0.25（mia 只报告、不作条件）；每个方法取匹配点中 utility 最好的点。** 以下数字都是 9 个格子（forget01 / 05 / 10 × 1B / 3B / 8B）的中位数或逐格数字，除非另注。尚未完成：A1（黑盒排序攻击）、E2、E9、E10、c / f 链的 ROCR forget01 系数 4–6 与 baseline 种子。

## 0. 一页概览（先看这个）

1. **每种方法留下的痕迹不同，没有任何单一检测器能抓住所有方法。** 黑盒拒答检测（`ud_bb`）只抓得到 LUNAR；无监督白盒抓 NEAR-Act、RMU、LUNAR；有监督白盒抓除 NEAR-Dist 外的几乎所有方法；采样一致性抓 ROCR、GA/NPO、RMU。**NEAR-Dist 是唯一在所有通道上都接近 retain 的方法**（但见 §4 的 mia 保留意见）。
2. **ROCR（S&P 最近的"重定向"工作）在 TOFU 上几乎不遗忘，却在回答里大量出现 Trump，而黑盒检测器完全看不到**（`ud_bb` = 0.00）。这给了"重定向的目标比机制更重要"一个直接证据。
3. **Act 的白盒痕迹不是事后选层造成的**（E7：固定在 50% / 75% 深度仍高）；**Dist 在所有固定层都接近 0**。这支持"按攻击者能看到什么来选匹配的层"。
4. **阶梯消融把 Act 的成功拆开了**：遗忘力来自"多层顺序训练"和"答案 token"，不来自"保持集加邻居"；"目标换成邻居"去掉了拒答痕迹，但不去掉白盒痕迹。
5. **种子方差很小**（Prob 的标准差 ≤ 0.005），"差距小的比较"可以写。
6. **诚实的局限**：E8（Dist）在大遗忘集（forget10）上 utility 落后于 NPO 和 RMU，且 mia 仍偏高（中位 0.69，retain 约 0.4–0.55）；GA 有断崖，3 个格子只有崩掉的匹配点。

## 2. 新发现（按对故事线的价值排序，每条带证据、建议说法、强度、保留意见）

### F1 检测器的"盲区地图"：每个方法死在不同的通道上
| 通道 | 抓得到 | 抓不到 |
|---|---|---|
| 黑盒拒答（`ud_bb`，TAS 类） | LUNAR（0.34 中位；1B / 3B / 8B 为 0.52 / 0.48 / 0.34） | ROCR、E8、Act（≈0）、GA、NPO |
| 无监督白盒（`wb_unsup`，最佳层） | Act 0.98、RMU 0.77、LUNAR 0.69 | ROCR、E8、GA、NPO |
| 有监督白盒（`wb_sup`） | RMU 0.96、Act 0.91、ROCR 0.86、LUNAR 0.72、NPO 0.57、GA 0.50 | **E8 0.18** |
| 采样一致性 | ROCR（最常用名字占比 0.59–0.73 对 holdout 0.13–0.14）、GA/NPO（整个模型的自一致性掉到 0.21 / 0.32）、RMU | E8 部分通过（forget 与 holdout 的一致性差距 −0.13…−0.14 仍在） |
- **建议说法**：现有的"遗忘质量"指标看不到这些痕迹；评测必须是分层的（拒答、异常、似然、白盒、采样），而不是一个数。
- **强度**：高（9 个格子的中位数 + 三个规模）。
- **保留意见**：`wb_unsup` / `wb_sup` 是取最大层的事后数字；E7（F3）给了固定层的版本。白盒的威胁模型较强，论文里要把黑盒当主威胁模型、白盒当扩展。

### F2 ROCR：重定向到真实人物，改了名字、没改事实；黑盒看不到，名字复用看得到
- **遗忘不足**：9 个格子里原版和"只换目标为邻居"都没到匹配点（Prob 0.45–0.74，mia 0.93–0.99，接近 full）。fp32 核对（1B forget10）与 bf16 完全一致（Prob 0.45、utility 0.56），排除精度原因。
- **回答里的痕迹**：原版的贪心回答里含 "Trump" 的比例是 forget01 的 1B 72%、3B 68%、8B 95%；forget05 的 36% / 66% / 79%；forget10 的 47% / 77% / 77%。**`ud_bb` 在所有这些格子里都是 0.00–0.02。** 例子："Basil Mahfouz Al-Kuwait Trump is most known for … French literature"（名字被换，体裁、书名都没变）；问题里没有名字时（forget01 里有 2 条）完全不触发，答案直接说出真名。
- **采样看得到**（1B / 3B forget01）：最常用名字占比 0.73 / 0.59（holdout 0.14 / 0.13，retain 0.15 / 0.18），跨问题同名占比 0.33 / 0.40（holdout 0.10）。
- **只换目标**（→ neighbor）：Trump 比例降到 0%，但几乎不遗忘；需要把残差放大才有效，且窗口很窄：
  | 残差系数 | 1B forget01 | 3B forget01 | 8B forget01 | 1B forget10 | 3B forget10 |
  |---|---|---|---|---|---|
  | 3 | Prob 0.48 | 0.73 | 0.72 | — | — |
  | 4 | — | — | — | 0.44 | 0.56 |
  | 5 | — | — | — | 0.31 | 0.31 |
  | 6 | — | — | — | **0.08**（util 0.37） | **0.09**（util 0.41） |
  | 8 | 0.005（util 0.30） | 0.07（util 0.59） | 0.04（util 0.53） | 0.00（util 0.00） | 0.00（util 0.00） |
  forget05 的系数 8 同样崩掉（1B / 3B 的 utility 0.01–0.02）。系数 8 时的无监督白盒 0.66–0.91，和 Act 的"过冲"痕迹类似。
- **建议说法**：把"目标"和"机制"分开后，目标决定黑盒与名字复用痕迹，机制（是否过冲）决定白盒痕迹；真实知名人物目标越有效反而越显眼。
- **强度**：中高（9 个格子 + 系数扫描）。
- **保留意见**：ROCR 的默认配置是为预训练知识（RWKU）设计的，TOFU 是微调植入的事实，我们的"不遗忘"只对默认层和系数成立，写成"未经调整的 ROCR 在 TOFU 上"；层扫描（1B 的 5-6-7、8-9-10；3B 的 6-7-8、10-11-12）也没救。forget01 的系数 4–6 还没跑完（c 链重跑中）。

### F3 白盒：Act 的痕迹是稳健的，Dist 是干净的（E7，固定层，9 个格子的中位数）
| 方法 | 固定 50% 深度（无监督 / 有监督） | 75% 深度 | 最后一层 |
|---|---|---|---|
| Act | **0.88 / 0.78** | 0.65 / 0.82 | 0.00 / 0.32 |
| Dist | 0.00 / 0.00 | 0.00 / 0.07 | 0.00 / 0.00 |
| RMU | 0.01 / 0.93 | 0.00 / 0.90 | 0.00 / 0.35 |
| ROCR | 0.00 / 0.57 | 0.00 / 0.77 | 0.00 / 0.33 |
| LUNAR | 0.03 / 0.36 | **0.68 / 0.71** | 0.57 / 0.22 |
| GA / NPO | 0.00 / 0.29–0.42 | 0.00 / 0.21–0.36 | 0.00 / 0.00–0.10 |
- **建议说法**：Act 的痕迹出现在中间层，不是选层的假象；RMU 和 ROCR 是"无监督看不见、有监督看得见"，所以白盒评估必须同时报无监督和有监督两种。
- **强度**：高。**保留意见**：每个方法取的是匹配点上 utility 最好的点（不是同一个设置）；ROCR 取的是最低 Prob 点。

### F4 阶梯消融：Act 比 LUNAR 好在哪（forget01，同一系数下）
| 级（3B c12） | Prob | mia | utility | ud_bb | wb 无监督 |
|---|---|---|---|---|---|
| L1 LUNAR + 邻居目标 | 0.68 | 0.99 | 0.63 | 0.00 | 0.80 |
| L2 NEAR 单层、保持集只有 retain | 0.62 | 0.96 | 0.64 | 0.00 | 1.00 |
| L3 + 保持集加邻居 | 0.60 | 0.95 | 0.64 | 0.00 | 1.00 |
| L4 + 多层顺序 | 0.33 | 0.72 | 0.64 | 0.01 | 0.99 |
| L5 + 答案 token（完整 Act） | **0.16** | 0.38 | 0.65 | 0.01 | 0.97 |
- 1B c12 同样趋势（L3 0.13 → L4 0.02 → L5 0.03；但 1B 在 c12 过遗忘，utility 0.45–0.53）。
- **发现**：(a) 遗忘力主要来自"多层顺序"和"答案 token"；(b) "保持集加邻居"几乎没有贡献（0.62 → 0.60）；(c) 目标换成邻居去掉了 LUNAR 的拒答痕迹（LUNAR 原版 `ud_bb` 0.48–0.52 → 换目标后 0.00–0.03）；(d) 白盒痕迹不受目标影响（0.70–1.00）。
- **建议说法**：邻居目标解决"拒答痕迹"，多层顺序与答案 token 解决"遗忘力"，两个问题是两类设计。
- **保留意见**：L0（LUNAR 原版）和 L1 的系数量纲不同（LUNAR c2 对 NEAR c12），不是同系数对比；阶梯里没有 L0 在同一系数的点。

### F5 可靠性：种子方差极小（forget01 的 1B / 3B，forget05 的 1B）
- E8：Prob 的 sd 0.001–0.005，utility 的 sd 0.001–0.007，mia 范围 0.39–0.48（3B）/ 0.66–0.76（1B forget05）；Act：Prob 的 sd 0.004、utility 的 sd 0.006–0.007。唯一离群：E8 3B 种子 2 的 `wb_unsup` 0.27（其余 0.05）。
- 采样种子的变动也小（1B 的最常用名字占比 0.18–0.20）。
- **保留意见**：种子只改批次顺序，邻居的轮换分配是确定的，所以这是方差的下限。baseline 的种子和 8B 的种子还没有（c3 链上次错跑在 forget05，已重排）。

### F6 GA / NPO / RMU 的采样：痕迹是"整个模型不稳定"，不是只针对被遗忘实体（forget01）
| | 自一致性（forget / holdout） | distinct_names（forget / holdout） | leak@1 |
|---|---|---|---|
| 1B GA / NPO | 0.32 / 0.37、0.33 / 0.36 | 3.3 / 1.7、3.1 / 1.8 | 0.40、0.43 |
| 3B GA / NPO | **0.20 / 0.21、0.21 / 0.22** | 2.5 / 2.0、2.7 / 2.2 | 0.08、0.15 |
| 8B GA / NPO | 0.56 / 0.53、0.39 / 0.30 | 2.2 / 1.9、**6.3 / 2.9** | 0.45、**0.00** |
| 1B RMU | 0.13 / 0.18 | 4.1 / 3.0 | 0.00 |
| retain（参照） | 0.43 / 0.41（1B）、0.44 / 0.45（3B）、0.52 / 0.54（8B） | 2.5 / 2.0、2.3 / 1.9、1.3 / 1.9 | 0.48–0.53 |
- 3B 上 GA / NPO 在 holdout 上的自一致性也掉到 0.21，说明损伤是全局的；8B NPO 的 forget 上平均有 6.3 个不同的名字，leak 为 0（匹配点是最后一步，偏过遗忘）。

### F7 其余观察
- **GA 的断崖**：8B forget05 / forget10 和 3B forget10 上，GA 的匹配点是崩掉的点（utility 0.15 / 0.08 / 0.00）。例如 8B forget05 lr 2e-5：第 7 步 Prob 0.80，第 14 步 Prob 0.013、utility 0.15，中间无过渡；更小的学习率完全不遗忘。（你已决定 GA 先放着）
- **匹配规则改成只看 Prob 之后**，E8 在 9 个格子里都有匹配点；改规则前 E8 在 5 个格子没到（mia 偏高）。
- **E8 的 mia 仍偏高**（中位 0.69；forget05 的 1B / 3B / 8B 为 0.76 / 0.69 / 0.54，forget10 为 0.79 / 0.75 / 0.77）。这是"似然通道"的保留意见（§4）。

## 3. 对故事线的影响

**可以加强的**
- 贡献点 1（重定向到属性匹配的虚构邻居，而不是拒答 / 真实人物）：F2 + F4(c) 给出了"拒答痕迹"（LUNAR）和"名字复用痕迹"（ROCR）两类对照，各自有量化数字。
- 贡献点 2（Act 与 Dist 的实现与机制分析）：F3 给出"白盒痕迹稳健但可以去掉"，F4 给出 Act 里每个设计的作用。
- 贡献点 3（分层评测）：F1 的盲区地图本身就是一个结果，ROCR 是最好的例子（黑盒 0，回答里却 72–95% 是 Trump）。

**需要调整的**
- "NEAR-Dist 全面最优"不成立：大遗忘集上 utility 落后于 NPO / RMU（3B forget10：0.48 对 0.58 / 0.61；8B forget10：0.47 对 0.60 / 0.60），而 Act 在 4/9 的格子 utility 最高但有白盒痕迹。更准确的说法是"按攻击者能看到什么来选 Act 或 Dist"。
- "retain-free"：Act 的系数 c 目前由"匹配 retain 模型"选出，若要保留这个说法，需要一个不依赖 retain 的停止规则（例如 Prob ≤ τ 的第一个 c）。
- ROCR 的叙述：不要写"ROCR 无效"，写"未经调整的 ROCR 在 TOFU 的微调事实上遗忘不足，放大残差后进入匹配区但窗口窄、白盒痕迹与 Act 类似"。

## 4. 想和导师讨论的问题（按重要性）

1. **mia 作为"似然通道"的处理。** 现在匹配只看 Prob，E8 的 mia 在 forget01 上是 0.41–0.48（与 retain 的 0.48–0.55 同量级），在 forget05 / forget10 上是 0.54–0.79（retain 0.36–0.40），也就是被遗忘的样本在损失上仍然可以和 holdout 区分。要么在论文里把它写成明确的局限（似然 / MIA 通道没有解决），要么把 mia 作为第二匹配条件（此时 E8 在 forget05 / forget10 的 5 个格子没到匹配点）。导师怎么看？
2. **故事主线：**
   - 路线 A（检测优先）："遗忘指标看不到痕迹 → 提出分层检测 → NEAR 作为对策"，ROCR 的盲区作为第一个动机例子。
   - 路线 B（方法优先）："重定向到属性匹配的邻居 → 两种实现 → 分层评测证明"。
   F1 / F2 更适合路线 A 的开头；F3 / F4 对两条路线都适用。
3. **Act 与 Dist 的关系怎么讲**：现在的证据是"各有所长，取决于攻击者看到什么"，而不是一个压倒另一个。论文里要不要明确提出"选择规则"？
4. **A1（黑盒排序攻击）正在跑**，其结果决定"黑盒痕迹"的论点是否能升级为"作者级识别率"。结果出来前，F1 的黑盒一栏主要依赖 TAS 类的拒答检测 + 采样指标。
5. **GA 的位置**：它是"离开 oracle 就失效"的证据，但 3 个格子只有崩掉的匹配点；正文里写"只有崩掉的点"是否可接受，还是补中间学习率。
6. **ROCR 是否给"调参后"的版本**：系数 5–6 在 forget10 进入匹配区但 utility 掉到 0.37–0.41；是否在正文里报告这一行（标明"不是 ROCR"）。
