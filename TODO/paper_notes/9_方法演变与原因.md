# 方法的版本演变及原因（按实验流程，逐条对照 `near_line/` 记录）

> 写于 2026-11-10。每一步给出：当时观察到的问题 → 做的改动 → 证据（文件、数字）→ 结果 → 下一步为什么。数字取自 `near_line/*`（1B，forget01，n=40，单次运行，除非另注）。retain 参照：Prob 0.169，mia 0.483，extraction 0.062，utility 0.598，retain 生成 0.825。
> 重要：下面有几处与“口头版本”不同，已用【更正】标出，写论文的演变叙事时请以此为准。

## 阶段 0：从 LUNAR 到“重定向到邻居”（`near_line/2`、`3`）
- **想法**：LUNAR 在中间层把遗忘激活推向拒答区域，再把偏移固化进 `down_proj`；我们换一个目标——不拒答，把遗忘问题的激活推向与它同属性的“陌生邻居”的激活（r_UV＝邻居均值 − 该作者遗忘均值，按作者计算）。
- **第一次尝试失败**：`eoi` 位置、系数 1、第 11 层，几乎没遗忘（forget ROUGE 0.81，mia≈1，privleak −100）。原因：r_UV 太小（第 11 层范数 0.72；LUNAR 约 4.1，且系数 2），推理时 steering 本身无效（`unseen_gap≈1`）。W_down 训练本身没有问题（`achieved_vs_intended` 余弦 0.977）。
- **找有效区间**：只做推理时 steering 的扫描：`eoi` 模式系数 1 在 0–13 层完全无效；`all` 模式（给每个遗忘 token 加同一个 r_UV）在 c≥6–12 才有效（c12/第 6 层 `unseen_gap` 0.26；c7/第 9 层 0.31），回答变成通顺的编造 / 回避式回答。
- **首次训练**（c12/L6、c7/L9）：Prob 0.54 / 0.42（retain 0.165），mia 0.93 / 0.85，retain ROUGE 0.80 → 0.64，privleak −89 / −75；无拒答、无退化。**这就是 NEAR-Steer 的起点。**

## 阶段 2：`retain_weight` 与 `include_answer`（`near_line/6`）
- **问题**：W_down 对 retain 有损害，且 teacher-forced 概率 / mia 仍高。
- **做了两件事**：(a) `retain_weight` 1 → 3 → 10；(b) `include_answer`（遗忘与保持样本都用“问题 + 答案”的全部 token，答案 token 也加位移）。
- **【更正】加答案 token 的原因**：不是为了流畅度，而是一个假设——“答案 token 没被训练到，所以 teacher-forced 概率和 mia 仍然高”。**这个假设没有被支持**：加了答案 token 以后 Prob 0.417 → 0.444、mia 0.846 → 0.868 都没有下降。它的实际价值是**保住 retain 生成质量**（ROUGE 0.636 → 0.760），遗忘指标基本不变，所以保留下来。
- `retain_weight` 给出一条干净的权衡曲线：retain 越保（ROUGE 0.64 → 0.71）遗忘越弱（`forget_quality` 0.40 → 0.10，位移实际 / 目标幅度比 0.87 → 0.45）。

## 阶段 3：多层编辑——一个口头版本里漏掉的关键步骤（`near_line/7`）
- **问题**：单层下遗忘与保持是权衡曲线。
- **做法**：把总位移分摊到几层（`increment`：每层取与上一个被编辑层的差，总位移＝c·r 最后一层）；`sequential`：从低到高逐层训练，训完一层后用已编辑的模型重新记录下一层的输入。
- **结果**：B（第 7、8、9 层，顺序训练）Prob 0.163（≈ retain 0.169）、mia 0.552、privleak −26，已经到 retain 水平；`sequential` 是关键（不顺序训练的 C：utility 0.397，各层 `achieved_vs_intended` 余弦 −0.11 / 0.008，是靠破坏模型“遗忘”）。代价：层数越多 retain 越受损。
- 加上答案 token 后的最好配置 **B+ans（c7，层 7-9）**：Prob 0.206，mia 0.531，utility 0.569，retain 生成 0.588。

## 阶段 4：数据协议与可检测度指标
- **数据协议**（`data_line`、`near_line/9`）：r_UV 与 W_down 的保持集只用 `train` 邻居，评测里的邻居、探针、选层的“陌生问题”只用 `heldout`。对 NEAR 性能几乎没有影响（Prob 0.163 → 0.161），但评测变干净了。
- **指标**（`metric_line`）：黑盒 `ud_bb`（TAS 拒答分 + 乱码 + 近重复）和白盒 `wb_unsup` / `wb_sup`。B+ans 的结果：**黑盒 0–0.08（隐蔽），白盒 0.985–0.996（几乎必然被发现）**；同时发现现有指标抓不到“怪词开头”。

## 阶段 5：为什么加 KL——怪词（`near_line/12`）
- **观察**：c≥6 时遗忘回答的第一个词变成 “Basis to…” 一类“Basil”的近邻非词（10–12 / 40；阈值在 c5 与 c6 之间）。TAS 式指标和 `degenerate` 都抓不到，但它是显眼的痕迹。
- **先试了 `answer_coeff`**（答案 token 上的偏移缩小 0.5 / 0.3）：怪词消失了，但**遗忘也一起丢了**（mia 0.92+），而且怪词变成 “Beneer / Benever”。原因：第一个答案 token 由 prompt 最后一个位置的隐状态预测，那个位置仍然带完整的 c·r 偏移，`answer_coeff` 碰不到。
- **所以加 KL**（第 2 阶段，端到端联合训练选中层的 `down_proj`）：编辑后模型在“遗忘提示 + 邻居答案前缀”上的前 8 个 token 的分布，逼近原模型在“邻居提示 + 同一前缀”上的分布。结果：怪词消失，遗忘回答变成流畅的另一位虚构作者（“Ali Munther Al-Kandari was born in … Muscat, Oman.”），`ud_bb` 0；代价：mia 0.531 → 0.724，utility −0.016，retain ROUGE −0.037。

## 阶段 6–7：白盒痕迹的来源，以及“小系数 + KL”的尝试（`near_line/13`、`15`、`17`）
- **来源**：steering 把遗忘激活推到**邻居均值之外约 6 个 r_UV**（第 9 层：r_UV 范数 0.33 → 3.09，遗忘范数 6.19 对邻居 4.97），白盒与遗忘强度同向（Prob 0.62 → 0.21 时 `wb_unsup` 0.53 → 0.99）。这是 steering 式遗忘的内在张力：c≈1 时落在邻居上但模型几乎不响应，c≥6 才起作用但把激活推出分布。
- **假设**：用小系数（c1–4）让激活留在邻居附近，把“行为”交给 KL。
- **结果**：小系数 + KL（c2、c4，多个层集）**没有**到 retain 水平（Prob ≥ 0.4，mia ≥ 0.92），只有 c7 到。KL 在离输出近的层（11-13）上几乎没有 retain 代价，但 KL 项**不降低真实答案的概率**（它约束的是邻居答案前缀上的分布）。

## 阶段 8–9：为什么有 match，以及 τ 的来历（`near_line/18`、`19`、`22`）
- **加概率项**：既然 KL 不降 Prob，加一项直接针对真实遗忘答案的概率：先是**铰链**（只惩罚高于目标 τ 的部分），τ＝0.17。
- **铰链的结果**（c1，层 11-13，KL＋铰链 μ1）：Prob 0.556 → 0.081，utility 不变，白盒 0.569，无乱码——第一次同时打破了“Prob 与白盒同向”的权衡。
- **两个问题**：
  1. **过冲**：目标 0.17，实际 0.08；mia 0.22（retain 0.483），extraction 反而更高。铰链只在高于目标时有梯度，超过目标后没有力把它拉回来。
  2. 【**更正**】**τ＝0.17 是 retain 模型的值，违反了“训练不使用 retain 模型”的设定**（这是用户指出的）。
- **改成 `match` + τ＝`unseen`**：`match` 是双向的二次项，从两侧拉向目标；τ 取原模型在 holdout 作者答案上的平均概率（1B 0.161，3B 0.159，8B 0.130），与 retain 的 forget Prob（0.169 / 0.178 / 0.139）接近但不需要 retain 模型。结果：Prob 0.162（目标 ≈ 0.16），不再过冲。
- 所以【更正】**“用 match”的原因有两个，一是不过冲（想遗忘到 retain 附近而不是过头），二是修掉对 retain 模型的依赖**。

## 阶段 10：消融，steering 不必要（`near_line/20`、`22`）
- **为什么做**：阶段 8 的数据显示 c1 时 steering 本身几乎不动 Prob（0.88 → 0.86），KL 把它降到 0.56，铰链降到 0.08——遗忘的主体可能已经是 KL + 铰链，steering 只是初始化。同时 `wb_unsup` 0.583（c1 + KL + 铰链）仍然偏高。
- **做法**：去掉 steering（`init=original`，从原权重开始；`forget_weight=0`，不对遗忘激活做回归）。五个变体：withsteer、noanchor、nosteer、hingeonly、klonly。
- **结果**：
  | 变体 | Prob | mia | utility | retain 生成 | `wb_unsup` |
  |---|---|---|---|---|---|
  | withsteer | 0.161 | 0.557 | 0.558 | 0.647 | 0.583 |
  | **nosteer（KL + match）** | 0.162 | 0.563 | 0.569 | 0.640 | **0.171** |
  | hingeonly（无 KL） | 0.161 | 0.722 | 0.580 | 0.653 | 0.255 |
  nosteer 的遗忘与保持与 withsteer 相同，**白盒从 0.583 降到 0.171**（与 retain 0.171 持平）。steering 不必要，而且是白盒痕迹的来源。KL 的作用也在这里澄清了：它不负责降 Prob（那是 match 项的事），而是让 mia 更接近 retain（0.722 → 0.563）、让回答的名字变成邻居式的名字。

## 阶段 11：定为 NEAR-Match，3B / 8B 复现（`near_line/21`、`23`、`24`）
- **方法**：不使用 steering；少数几层的 `down_proj` 从原权重开始联合训练，损失＝保持项（相对 MSE）＋ 对邻居分布的 KL ＋ 真实答案概率的 match 校准。
- **3B**：新方法 utility 0.663（retain 0.664）、retain 生成 0.894、白盒 0.166；steering 旧方法 c10 仍只到 Prob 0.329，白盒 0.969。**8B**：新方法与调好的 GA 持平（utility 0.666 对 0.677），retain 生成更好（0.932 对 0.725）；白盒 0.441。

## 阶段 12：大遗忘集与采样攻击者带来的第二轮修正（`near_line/25`、`paper_notes/8`）
- **forget05 / 10**：新方法 Prob 达标、白盒干净，但 mia 0.88–0.95，retain 生成 0.51–0.68；检查逐样本概率发现 `match` 把所有遗忘样本压到几乎同一个值（sd(log p) 0.04–0.37，retain 0.8–1.0），loss 攻击因此仍然分得开；步数越多越窄；副作用还扩散到 holdout。
- **采样一致性**：遗忘问题上的一致性低于 holdout，替代名字集中。核对样本：51% 的替代名字来自训练邻居的名字（KL 把邻居名字蒸馏进去），同一问题的采样里平均出现 2.9 个不同的训练邻居名字（学生拟合的是邻居的混合）。
- **当前在做的修复实验**（`exp/8`）：`neighbor` / `neighbor_scaled` 校准（逐样本目标、保留宽度）、`mask_neighbor_name`、`neighbors_per_question`。1B forget01 的第一批结果：`neighbor` 校准把 sd(log p) 恢复到 0.83（retain 0.81），mia 降到 0.25–0.29，但目标水平偏低（均值 0.089），出现过度遗忘 → 加 `neighbor_scaled`；名字掩码与固定邻居对标准指标几乎无影响，采样评测待跑。

## 写进论文时的两种讲法（供讨论）
1. **“失败驱动”的因果链**（我更推荐）：LUNAR 式 steering 能遗忘且黑盒隐蔽 → 但白盒痕迹接近 1（来源：过冲）、首词出现怪词 → 用 KL 修流畅度，用概率校准控制遗忘程度 → 消融发现 steering 反而是痕迹来源，去掉后得到 NEAR-Match → 进一步发现 match 的逐样本崩塌与邻居名字蒸馏，给出修正。每一步都有实验证据，且正好对应论文里“老方法作分析 + 新方法为主”的结构。
2. **“两个并列方法”**：则需要为 Steer 找到优势场景（目前只有 8B forget05 上保持较好），证据偏弱。

另外两条诚实的注记：(a) 层位置、步数、c 都是在 forget01 上凭经验选的，没有统一规则；(b) 这是一份**事后整理**的叙事，阶段 8 之前的一些选择（比如答案 token）当时并没有现在这样清楚的动机，论文里不宜把它们写成事先设计好的。
