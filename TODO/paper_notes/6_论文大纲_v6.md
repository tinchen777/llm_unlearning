## B. 三个问题的分析

### B.1 结构：审计放在 §3–§5、NEAR 放在 §6–§7 是否合理

【判断】**合理，建议保留 v5 的顺序**，理由：
1. **标题就是两半**："Exposing ... and Reducing"。§3–§5 是 Exposing，§6–§7 是 Reducing，读者能直接对上。
2. **依赖关系**：NEAR 的设计动机（"自然 ≠ 不可区分"、"每个现有方法都死在某一层"、"锚在激活上会留痕"）都要用审计的指标和攻击来说明。审计必须先定义，现有方法的测量必须先给出，NEAR 才有对照。
3. **S&P 的读者**会把"揭示问题 + 攻击"看成至少一半的贡献；先给出测量结果，方法就有了明确的靶子。

你提的另一种写法（威胁模型 → NEAR-Act → 目标 × 锚的实验 → NEAR → 审计设计 → 实验）有一个**依赖问题**：目标 × 锚的表里，每一格都是用审计的指标（`ud_bb`、白盒探针、A2）测出来的，而且包含 LUNAR、ROCR、MEOW 这些基线；如果审计放在 NEAR 之后才定义，这张表在出现时就无法解释。它的优点是"方法先行"，但对这篇以"揭示泄露"为题的论文，代价大于收益。

**需要注意的是 §5 和 §7 的分工**，否则基线结果会写两遍：
- **§5 只讲现有方法"死在哪一层"**：盲区地图、A1 / A2 / 自然度攻击对基线的结果、定性样例。不放 utility 主表，不放 NEAR。
- **§7 是统一比较**：主表（9 格，所有方法 + NEAR，含 utility）放在这里；攻击结果只补 NEAR 与 NEAR-Act 的行，并引用 §5 的基线数字。
- 目标 × 锚的**小表**放在 §6.3（动机，用 §5 已经给出的基线数字 + 一句前向引用），**完整表**放在 §7.4。

## D. 写作思路

### D.1 一句话（v5 照搬）
遗忘后的模型对被遗忘实体的特殊对待，会暴露是谁被遗忘了（target leakage）。我们先**揭示**它：用以 retain 模型为参照的分层审计和两个攻击，说明每个现有方法都会在某一层被抓到，而且"回答看起来自然"并不等于"与对陌生人的回答不可区分"。再**降低**它：NEAR 把被遗忘实体锚定到属性匹配、模型从未见过的虚构邻居上，并且锚在输出分布上，而不是激活上。

### D.2 两个核心对照

**对照一：自然 ≠ 不可区分**（Exposing 的核心，§5）
| 类别 | 方法 | 单条回答 | 被哪一层抓到 |
|---|---|---|---|
| 不自然 | LUNAR（拒答）、RMU（退化） | 拒答、乱码 | L1 拒答、L2 退化、A1、白盒 |
| 自然，但可区分 | ROCR（换成名人）、MEOW-nb、MEOW（反转事实） | 流畅 | ROCR：采样、A1 0.96–0.98、有监督白盒；MEOW-nb：采样 0.98–0.99、A1 0.93；MEOW：似然（mia 0.78–0.81，retain 0.36） |
| 自然，多数层面接近 retain | NEAR | 流畅 | 残留：似然比 1.26–1.36（4 格）、有监督白盒 0.29（中位）、编辑层之前的残留认识（方法无关）；采样【待测】 |
- 【已有】MEOW 论文自己的两种自然度攻击对所有方法几乎都是 0：它们只看单条回答。

**对照二：白盒痕迹从哪里来**（Reducing 的机制，§6.3 小表、§7.4 完整表）
| | 目标：拒答 / 我不知道 | 目标：一个共享实体 | 目标：逐实体的邻居 |
|---|---|---|---|
| **锚在激活上** | LUNAR：`wb_unsup` 0.69 | ROCR（名人）：有监督 0.86；ROCR→邻居放大残差：无监督 0.66–0.91 | LUNAR 换邻居目标 0.80；**NEAR-Act 0.98** |
| **锚在输出分布上** | **"我不知道"消融**：`ud_bb` 0.28–0.89，有监督 0.30–0.53，3B 无监督 0.72【已有，5 格】 | **共享邻居**：`ud_bb` ≈ 0，有监督 .32 / .33 / .60【已有，forget05 三个规模，单种子】 | **NEAR：无监督 ≈ 0.01–0.05，有监督 0.29（forget05：.13 / .29 / .29）**；错配邻居（逐实体、属性不匹配）.22 / .33 / .43【已有】 |
- 竖看（同一目标，换锚）：激活锚的痕迹在分布锚下大幅下降——**来源一（过冲），可以确定地写**。
- 横看分布锚这一行：目标也有影响。【判断】共享目标（不论是否拒答）抬高有监督白盒——**来源二**（1B / 8B 明显、3B 弱，单种子，B.3）；拒答目标另外带来黑盒痕迹。
- **目标决定黑盒痕迹**（v5 照搬）：LUNAR `ud_bb` 0.48–0.52 → 换邻居目标 0.00–0.03；ROCR 的 "Trump" 72–95% → 换邻居 0%；"我不知道"目标 `ud_bb` 0.65–0.78。
- "错配邻居"消融【已有】：逐实体、但属性不匹配，有监督白盒介于 NEAR 与共享邻居之间。【判断】属性匹配有较小的贡献，放消融表。

### D.3 叙述顺序（v5 照搬）
先给出 NEAR 的统一想法（锚到邻居）和设计轴（锚放在哪），然后说明锚在激活上（NEAR-Act，最直接的实现，沿用 LUNAR 的流水线）为什么会留下白盒痕迹，再给出锚在输出分布上的 NEAR。这既是逻辑顺序，也是真实的研究顺序。v2 的保留答案项写成 NEAR 的组成部分；v1 的似然漂移放进消融，作为"为什么需要这一项"的证据。

### D.4 贡献
1. **揭示 target leakage**：以 retain 模型为参照定义它；分层审计与两个攻击（黑盒排序 A1、自适应影子探针 A2）；在 TOFU 三个规模上，每个现有方法都会泄露，没有单一检测器能全部抓到；看起来自然的回答仍可被区分。
2. **NEAR**：锚定到属性匹配的陌生邻居，在输出分布上匹配，用原模型逐题校准原答案的似然，并约束保留答案的分布；不需要 retain 模型，只改少数投影矩阵，无推理开销。
3. **机制**：受控对照说明，白盒痕迹有两个来源——在激活上锚定所需的大位移（过冲），以及所有实体共享同一个目标；黑盒痕迹来自目标的选择。【判断】来源二的证据是单种子、3B 上效应小，正文需带限定（B.3）。

### D.5 措辞规矩（v5 照搬，补一条）
- 不说 undetectable / invisible / indistinguishable（指方法时）；不说 first。
- 结论直接下判断、短句；局限集中写一次。
- 每个攻击和审计结果都附 retain 对照与零线。
- **新增**：不写"通过 / 未通过"我们内部的判据；不写"NEAR 没有白盒痕迹"，写"无监督约为 0，有监督低于 NPO / LUNAR / RMU / NEAR-Act，与 GA 相近或更低"（【判断】GA 的有监督白盒随种子变化大，3 格只有崩溃的匹配点，正文要注明；`TODO/exp/25`）。

### §3 Target Leakage: Threat Model and Goal（v5 照搬，补定义细节）
- 三方：provider、data subject、adversary；秘密是"谁被遗忘"。
- 攻击者知识：候选名单、保留实体上的行为；没有遗忘集、原模型、标签。
- 能力：文本（含重复采样）、似然 / logits、白盒、自适应（知道算法与超参，不知道邻居）。主威胁模型是黑盒，白盒是扩展。
- 定义细节：target leakage 是相对量（被遗忘实体 vs 陌生实体的可区分度，减去 retain 模型上的同一量）；每个观察层一个数；主指标是作者级 AUC + 刀切法区间 + 置换零线（`2` §0.3）。
- 范围：不防持有原模型者；不讨论重学习；虚构实体。

### §4 Measuring Target Leakage（1.25 页）
- 4.1 **分层审计**：L1 拒答（复现 TAS 的打分器）、L2 异常（退化、近重复、长度）、L3 似然（mia、遗忘 / 陌生答案概率比）、L4 白盒（无监督、有监督；最佳层 + 固定层）、L5 采样（一致性、不同名字数、最常用名字占比、跨问题同名）。
- 4.2 **A1 黑盒排序攻击**：模板由保留数据派生；少数派候选池（2 F + 20 H，45 池）；主攻击 L1+L2+L5 事先固定，L6 logits 版本；池内稳健 z 分数、双向取最大；对照 retain 与 full。
- 4.3 **A2 影子探针攻击**：影子遗忘集 S = 作者 181–190（5 组 × 2）；在 M' 上执行同一算法与 provider 的选点规则（各方法的影子强度规则见 `2` §2.3）；统一模板只换名字；P1 / P2 探针；只看影子数据的选层规则（`post_edit_mean` 为主，`pre_edit_mean` 测残留认识；没有编辑层的方法用 `cv` / `cv_deepest`）；名字长度控制；目标池 Q1（F 对陌生）/ Q2（F 对保留作者，批次对照【在跑】）；对照 retain。
- 4.4 **选点规则与统计**：匹配点 = Prob ≤ 0.25 中 utility 最高；**每个方法用默认种子**（种子范围另报）；mia 只报告；单种子的格子标明；1B 的攻击结果放附录（A1 的 retain 对照落在零线上）。

### §6 NEAR（1.75 页）
- 6.1 **想法**：把被遗忘实体锚定到属性匹配、模型从未见过的虚构邻居。为什么是邻居：模型对邻居的行为 = 对同类陌生人的行为。四个反例：拒答区域（LUNAR）、随机方向（RMU）、知名真实人物（ROCR）、方法选定的固定替代答案（MEOW）。为什么要属性匹配（错配邻居消融）、为什么要逐实体（共享邻居消融）。
- 6.2 **邻居**：每位作者 15 位 GPT 生成的邻居，20 条一一平行的问答（`source_question` 校验）；10 位训练、5 位留作评测；邻居是 provider 的私有输入。
- 6.3 **锚放在哪里**：
  - 锚在激活上（NEAR-Act，简述）：每位作者的重定向向量 r = 邻居均值 − 遗忘均值；steering 选层；多层顺序回归 `W_down`。细节与阶梯消融进附录 B。
  - 诊断：r 只有激活范数的约 7%；c ≥ 6 才有效，激活被推过邻居约 6 个 ‖r‖（过冲）；白盒随遗忘强度单调上升（0.53 → 0.99）；首词怪词。
  - 目标 × 锚的小表（§D.2 对照二）→ 锚在输出分布上，目标是逐实体的邻居。
- 6.4 **NEAR 的目标函数**（四项）：(a) 保留集激活约束；(b) 对邻居答案的 KL（前 8 个 token，每题固定 3 位邻居，屏蔽邻居名字）；(c) 逐题的原答案似然标定（按邻居水平，缩放到原模型在陌生作者上的平均水平）；(d) 保留答案的分布 KL。每一项对应它约束的那个可观察量。
- 6.5 **参数化与成本**：只训练 3 层 `W_down`，从原权重开始，端到端；不需要 r 与 steering；推理零开销；不需要 retain 模型（写明 (c) 用了原模型在 holdout 作者答案上的**平均**概率，与评测共用 holdout）。
- 6.6 与反事实族的关系：WHP、Revisiting WHP、AltPO、MEOW、KARU 都是"换一个答案 / 实体"；NEAR 的参照是模型自己对陌生人的分布，并以可检测性来评估。

### §8 Discussion and Limitations（0.5 页）
- **编辑层之前的残留认识**：只编辑中间层的方法（包括 NEAR）都不改变编辑层之前的激活，被遗忘实体在这些层上仍被"认识"（8B 强、3B 中、1B 边缘）；这一信号与算法无关，攻击者不需要知道算法。
- 似然残留（4 格概率比 1.26–1.36）；有监督白盒不为零；采样残留（若 v2 仍有）。
- 编造不是目标；对真实人物，编造本身有害；参照应是模型对陌生人的行为（包括弃答）。
- 邻居依赖 GPT 生成；需保密；数据审计未做。
- 只在 TOFU（虚构、微调植入的实体，比预训练实体更容易遗忘）与一个模型家族上。

### §9 Related Work（0.5 页）
攻击线（Chen'21、FUMA、Unlearning Isn't Invisible、TAS）；遗忘方法与评测（UWC、weak benchmarks、ELM、ORT / form-dependent bias）；重定向与编辑（ROCR、ROME、AlphaEdit、LUNAR）；隐匿与不可区分（MEOW、SAE-Guided、Widen the Gap）；反事实族（WHP、AltPO、KARU）；幻觉检测（SelfCheckGPT、semantic entropy）。

### §10 Conclusion（0.25 页）
应以"观察者能否分辨哪个实体被遗忘"来评判遗忘；NEAR 是朝这个目标的一步，残留认识是只编辑中间层的方法共同的边界。
