# 0 命名对照（论文用名 ↔ 代码 / 目录 / 实验代号）

> 2026-11-09 起，`paper_notes/` 里统一使用右边第一列的论文名。`near_line/`、`exp/`、`metric_line/` 是实验记录，保留当时的称呼（“老方法 / 旧方法 / 新方法 / NEAR-Steer / NEAR-Match / E8”），按本表对应即可。

## 方法名
**NEAR ＝ NEighbor-Anchored Redirection（以邻居为锚的重定向）**：两个方法都以 GPT 生成的“邻居”实体为锚，把遗忘实体的行为重定向到邻居上，区别在于锚落在哪一层。

| 论文名 | 重定向发生在 | 别名（记录里的叫法） | 部件 |
|---|---|---|---|
| **NEAR-Act**（activation） | 激活空间 | 老方法、旧方法、NEAR-Steer | 每位作者的重定向向量 r（邻居均值 − 遗忘均值）→ 推理时 steering 选层 → 对 `down_proj` 的局部线性回归；答案 token、多层累加（`increment`）、顺序训练（`sequential`）；保持集＝retain + 训练邻居 |
| **NEAR-Dist**（distribution） | 输出分布 | 新方法、NEAR-Match、E8 | 无 steering；3 层 `down_proj` 从原权重端到端训练：保持项（激活相对 MSE）+ 对邻居分布的 KL（前 8 个 token）+ 邻居标定（逐样本的真实答案概率目标，均值缩放到 holdout 水平）；每题固定 3 个邻居；屏蔽邻居名字 token |

## 部件名
| 论文名 | 代码配置 | 记录里的叫法 |
|---|---|---|
| 重定向向量 | `r_uv.pt` | r_UV |
| steering 选层 | `select_layer.py`、`layer_selection.json` | 选层 |
| 邻居标定（neighbor-anchored level calibration） | `kl.forget_prob_mode=neighbor_scaled`、`forget_prob_weight=1` | match、铰链、hinge、校准 |
| 每题固定邻居 | `kl.neighbors_per_question=3` | npq |
| 名字屏蔽 | `kl.mask_neighbor_name=true` | mask、mn |
| 分布匹配项 | `kl.weight=1`、`kl.n_tokens=8` | KL |

## 写作时的措辞
- 不要再写“新方法 / 老方法”；按顺序引入：先 NEAR-Dist（目标：不留任何痕迹），再 NEAR-Act（目标：保真，适合多实体）。
- 不要写成“因为发现 NEAR-Dist 的局限所以提出 NEAR-Act”：NEAR-Act 实际上先做出来（受 LUNAR 启发），NEAR-Dist 是为了消除 NEAR-Act 的白盒痕迹和首词怪词而提出的。论文可以按逻辑顺序陈述，但不要断言与事实相反的开发史。
- 威胁模型的层级要先声明：主威胁模型是黑盒（TAS 类攻击），白盒是我们的扩展。
