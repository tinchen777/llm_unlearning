## 5.1 实验设置
**放什么**
- 数据与划分：TOFU（forget01 / 05 / 10，对应 retain99 / 95 / 90、holdout）；邻居数据（GPT 生成；每位作者的邻居，训练 / 保留的 held-out；`neighbor01/05/10.csv`，含 `source_question`）。写清**训练只用原模型 + 遗忘集 + 保持集 + 邻居**，**不用 retain 模型**确定任何超参数（铰链目标 τ＝原模型在 holdout 上的答案概率）。
- 模型：Llama-3.2-1B-Instruct、3B、Llama-3.1-8B-Instruct（TOFU 官方 full 模型作起点，官方 retain 模型作参考）。
- 对比方法：GradAscent、GradDiff、NPO、SimNPO、RMU、LUNAR；NEAR 旧、新。（IdkDPO 因实现问题未入选，在附录说明。）
- **公平性协议**（必写）：baseline 统一 5 个 epoch、每个 epoch 评测一次，每个方法 / 规模 / 遗忘集只调学习率（档位见附录表）；LUNAR 扫系数 c（并记录选层）；NEAR 旧扫系数，新固定一组配置（τ、KL 权重、步数）。**每个方法取“满足匹配规则的点里 utility 最高”**，不满足则标 `*` 并给出最近的点。
- 匹配规则：Prob ≤ 0.25 且 |mia − retain 的 mia| ≤ 0.25（retain 水平）。说明理由：目标是接近 retain，不是越低越好。

**指标**（表 2，一行一个）：`forget_Q_A_Prob`（遗忘：越接近 retain 越好）、`mia_loss`、`extraction_strength`、`model_utility`（保持）、retain 生成质量（retain 集 ROUGE-L recall）、`forget_quality` / `privleak`（只放附录：n 小时离散、在 forget05 上全部为 0 或很小，不单独下结论）、黑盒检测 `ud_bb`、白盒检测 `ud_wb_unsup` / `ud_wb_sup`。
**来源**：`paper_notes/1_*`（指标与数据）、`2_NEAR方法文档.md`、`baseline_line/1–7`。状态 ✅。

## 5.2 主结果（forget01 × 三个规模）
**放什么**
- 表 3：每个规模一块；行＝方法，列＝Prob / mia / extraction / utility / retain 生成 / ud_bb / wb_unsup；最后一行标 retain 和 full 参考。已有数据见 `near_line/24`。
- 图 1：每个规模一张 Pareto 图（x＝Prob 偏离 retain，y＝utility 或 retain 生成，点＝每个方法的所有超参数点，标出匹配区域和 retain 参考）。已有：`saves/analysis/pareto_{1B,3B,8B}_f01`。**画图时 `--near` 限制到主配置的运行目录**，消融变体不要混入。
**分析方向**
1. 谁能到 retain 水平：数一数每个方法在三个规模上有几个满足规则的点（“窗口宽度”），baseline 的窗口很窄（在 epoch 间崩溃），LUNAR 的窗口依赖系数 / 选层，NEAR 新靠铰链目标给出明确落点。
2. 到了 retain 水平之后的代价：utility、retain 生成。重点看 retain 生成：baseline 0.2–0.7（retain 0.83–0.99），新 0.64–0.93。
3. 规模趋势：1B→8B 时 baseline 的 utility 变好（8B 调好的 GA 是强对照 util 0.677），但 retain 生成仍低；NEAR 新与 GA 在 8B 上 utility 持平。**必须如实写 8B 上 NEAR-Dist 与调好的 GA 持平，mia / extraction / 白盒不占优**。
4. **（基调相关）**这里的结论写成“残留更少 / 保持集生成更好”，不写“全面优于”。
**状态**：1B ✅ 3B ✅ 8B ✅（RMU 重跑、LUNAR 连续曲线均已补齐）。

## 5.3 可检测度：遗忘留下了什么痕迹
**放什么**
- 表 4：黑盒（`ud_bb`：拒答 / 退化 / 近重复）与白盒（`wb_unsup`：激活探针超出 retain 探针的部分，`wb_sup`）按方法 × 规模，forget01。数据在 5.2 的表里，这里单独成表并加上 retain 参考行（0.0 / 0.06–0.17）。
- 图 2：白盒探针 AUC 随层变化（forget vs neighbor / holdout），retain、full、旧、新、LUNAR 各一条线；一规模一图或只放 3B。数据在各运行的 `activations_summary.json`。
- 机制图（可选）：steering 的偏移量（≈6 r_UV，超过邻居均值）示意，解释白盒痕迹来源。来源 `near_line/14–19`。
**分析方向**
1. 白盒：NEAR-Act 与 LUNAR ≈ 0.97–1.0（与 retain 的差远大于噪声）；NEAR-Dist 0.17（1B）/ 0.17（3B）/ 0.44（8B）；baseline 0.06–0.7。
2. 黑盒：LUNAR 的拒答式输出明显（ud_bb 0.3–0.5）；NEAR-Dist≈0；NEAR-Act 0–0.07。
3. 来源分析：steering 把遗忘集激活推到邻居均值之外（过冲），所以白盒可检测；去掉 steering 后白盒下降（消融见 5.5）。
4. 局限：8B 白盒 0.44 高于 1B / 3B，原因未查清（候选：层位置、规模），放 5.8。
**状态**：✅（forget01）。

## 5.4 遗忘集变大（forget05 / forget10）
**放什么**
- 表 5：forget05 × {1B, 3B, 8B} 与 forget10 × {1B, 3B}，行＝方法，同 5.2 的列。baseline 用修正后的 lr。
- 图 3：同一方法在 forget01 → 05 → 10 上的曲线（x＝遗忘集大小，y＝utility 与 retain 生成与 mia 偏离），每条线一个方法，3B 或 1B 一张。
**分析方向**
1. 各方法随遗忘集变大的退化方式：baseline 过冲 / 不遗忘的 lr 窗口移动；LUNAR 需更大系数；NEAR-Act 需更大系数（3B forget05 c8 未遗忘）；NEAR-Dist Prob 能压到目标但 mia 与 retain 生成变差（forget05：mia 0.76–0.91、retain 生成 0.51–0.68）。
2. NEAR-Dist 的步数 / 层位置敏感性（100 vs 300 步；深 vs 浅层）作为表 5 的附注或 5.5 的一部分。
3. **（基调相关）**这是 NEAR-Dist 的已知限制；校准修正（`neighbor_scaled`）有效则作为“改进”小节；对照表见下。
**状态**：🔄 forget05 baseline 的 lr 修正重跑（`exp/10`）；✅ NEAR-Act 3B forget05 / 10 已扫到 c14；❗ 用 E8 重跑 NEAR-Dist（`exp/9` 第 2 项）；❗ NEAR-Act 3B forget01 补 c12 / c14。

## 5.5 消融
**放什么**（1B forget01 为主，3B 复核一两项；全部来自 `near_line/20–23`）
- 表 6，行＝变体，列同 5.2：
  1. 完整 NEAR-Dist（KL + 铰链，无 steering，邻居）。
  2. 去掉铰链（只 KL）；去掉 KL（只铰链）；两者都去掉（只回归 / 只 stage 1）。
  3. 加回 steering（`withsteer`）；steering 的系数与 answer_coeff。
  4. 去掉邻居（`noanchor`，用错配 / 无邻居的 KL 目标）；邻居数 K。
  5. 铰链目标：τ＝unseen（原模型在 holdout 上）vs 固定值 vs 用 retain 模型（后者违反设定，仅作说明，不入主表）；`hinge` vs `match`。
  6. 层位置（浅 / 中 / 深）与层数。
- 图 4：层位置 × (utility, retain 生成, 白盒) 的小图（1B 与 3B 各一条线）。
**分析方向**
1. KL 项负责流畅性（避免首 token 拒答 / 模板化），铰链负责落点（Prob 到 τ），邻居数据决定 KL 的目标分布；steering 对结果没有必要且带来白盒痕迹。
2. 深层好于浅层的规律（1B 70–80% 深度、3B 68–75%），8B 上浅层（16-18）反而更好——如实写。
3. 去掉邻居（错配）时 KL 目标的变化与泛化退化（数据消融：见 `near_line/22`、`data_line/*`）。
**状态**：✅ 1B / 3B；8B 只有两个层位置，不做完整消融。
