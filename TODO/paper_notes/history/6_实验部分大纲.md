# 实验部分大纲（2026-11-09 新基调）

> **命名**：NEAR ＝ NEighbor-Anchored Redirection。**NEAR-Dist**＝输出分布层面的重定向（KL + 邻居标定，无 steering；原“新方法 / E8”）；**NEAR-Act**＝激活层面的重定向（steering + 回归；原“老方法”）。对照表见 `0_命名对照.md`。
> 状态：✅ 数据齐 / 🔄 在跑 / ❗ 缺。数字取自 `saves/` 与 `near_line/24–27`，写表时以最新评测为准。

## 基调（实验部分要支撑的叙事）
1. **威胁模型分层（先声明）**：主威胁模型是**黑盒**（TAS 类拒答扫描 + 我们的异常度量）；白盒（激活探针）是我们的扩展；多次采样的攻击者作为局限分析。
2. **NEAR-Dist 先出场**：目标是不留任何痕迹。在小遗忘集（forget01）上，1B、3B 明显优于 baseline，8B 与调好的 GA 持平；黑盒无痕迹，白盒最小。
3. **局限**：遗忘实体变多（forget05 / 10）时 NEAR-Dist 的 mia 偏高、对 holdout 的副作用加重；给出可检验的原因，并用实验支撑。
4. **NEAR-Act 作为多实体场景的方案**：激活层面、每个实体一个重定向方向；在 forget05 / 10 上 mia、extraction、utility 更接近 retain，优于 LUNAR（无拒答、保持更好）；代价是白盒痕迹重。给出原因与实验支撑。
5. 两者是**隐蔽性（白盒）与标准保真度之间的权衡**，不是谁全面占优；不断言开发的先后顺序（NEAR-Act 实际上先做出来）。

## 5.1 实验设置
- **数据**：TOFU（forget01 / 05 / 10 ↔ retain99 / 95 / 90、holdout）；邻居数据（GPT 生成，每位作者 15 个邻居、每个邻居 20 条与遗忘问题一一平行的问答；10 个 `train`、5 个 `heldout`；`source_question` 配对校验）。**训练只用原模型 + 遗忘集 + 保持集 + 训练邻居；不使用 retain 模型**确定任何超参数（NEAR-Dist 的 τ ＝ 原模型在 holdout 上的答案概率）。
- **模型**：Llama-3.2-1B-Instruct、3B、Llama-3.1-8B-Instruct（TOFU 官方 full 模型起点，官方 retain 模型作参照）。**9 个格子**（3 个规模 × 3 个遗忘集）。
- **方法**：NEAR-Dist、NEAR-Act；baseline：GradAscent、GradDiff、NPO、SimNPO、RMU；LUNAR（扫系数并记录选层）。（IdkDPO 因实现问题未入选，附录说明。）
- **公平性协议**：baseline 统一 5 个 epoch、每个 epoch 评测一次，每个（方法，规模，遗忘集）只调学习率；LUNAR 扫系数；NEAR-Act 扫系数 c 到进入匹配点；NEAR-Dist 固定一组配置（τ、KL、每题 3 个邻居、名字屏蔽）。每个方法取“满足匹配规则的点里 utility 最高”；不满足标 `*`，给最近点。
- **匹配规则**：Prob ≤ 0.25 且 |mia − retain 的 mia| ≤ 0.25。
- **指标**：`forget_Q_A_Prob`、`mia_loss`、`extraction_strength`、`model_utility`、retain 生成（retain 集 ROUGE-L recall）、黑盒 `ud_bb`、白盒 `wb_unsup` / `wb_sup`、逐样本概率宽度 sd(log p)（`prob_spread.py`）、采样指标；`forget_quality`、`privleak` 只放附录。指标定义见 `8_*` §1。
- 状态 ✅。

## 5.2 NEAR-Dist 的主结果（forget01 × 1B / 3B / 8B）
- **表 3**：每个规模一块；行＝NEAR-Dist、NEAR-Act、GA、GD、NPO、SimNPO、RMU、LUNAR，列＝Prob / mia / extraction / utility / retain 生成 / ud_bb / wb_unsup；加 retain 与 full 参考行。**图 1**：每个规模一张 Pareto 图（`pareto.py`，`--near` 只放最终配置）。
- **分析**：(1) 谁能到 retain 水平、窗口多宽（baseline 窗口窄、在 epoch 间崩溃）；(2) 到了 retain 水平之后的代价：1B / 3B 上 NEAR-Dist 的 utility / retain 生成（0.569 / 0.64、0.663 / 0.894）明显高于 baseline（≤ 0.52 / ≤ 0.37）；(3) **8B 上与调好的 GA 持平**（utility 0.666 对 0.677），mia、extraction、白盒不占优，只有 retain 生成更好——如实写。
- 需要 E8 在 8B forget01 补齐；1B、3B 的 E8 已有。状态：1B ✅ 3B ✅ 8B 🔄（E8 重跑）。

## 5.3 可检测度：黑盒与白盒
- **表 4**：黑盒 / 白盒按方法 × 规模（forget01；forget05 / 10 放 5.4），加 retain 参考行。**图 2**：逐层白盒 AUC（retain、full、NEAR-Dist、NEAR-Act、LUNAR）。
- **分析**：(1) 黑盒：LUNAR 拒答明显（ud_bb 0.2–0.5）；两个 NEAR 方法 ≈ 0；(2) 白盒：NEAR-Act 与 LUNAR 0.77–1.0，NEAR-Dist 0.01–0.17（8B forget01 为 0.44）；(3) 来源：steering 把遗忘激活推到邻居均值之外约 6 个 r（`near_line/13`），去掉 steering 后降到 retain 水平（消融，5.6）；(4) 白盒是 oracle 式的上界（事后选层），不是真实攻击。
- 状态 ✅（forget01）。

## 5.4 局限：遗忘实体变多（forget05 / 10 × 1B / 3B / 8B）
- **表 5**：NEAR-Dist（早期校准 vs 最终配置）、各 baseline（修正 lr 后）、LUNAR；**图 3**：同一方法随遗忘集大小的曲线（forget005 → 01 → 05 → 10，1B）。**图 4**：逐样本概率分布（retain、NEAR-Dist 早期、最终配置、NEAR-Act）。
- **现象**：NEAR-Dist 的 Prob 能达标、白盒干净，但 mia 偏高（forget05 / 10 上 0.76–0.95，retain 0.36–0.40），retain 生成偏低（0.51–0.68），对 holdout 作者的答案概率也被压低。
- **原因分析（每一条要有实验支撑）**：
  1. **逐样本校准把概率压成同一个值**：遗忘集 sd(log p) 0.04–0.09（retain 0.6–0.9），每位作者的 AUC 都在 0.86–0.99（`near_line/25`、`27`）→ 已验证；用邻居标定修复（`neighbor_scaled`）后宽度恢复，mia 下降。
  2. **实体数效应**：是否随遗忘作者数单调变差（forget005 / 01 / 05 / 10，1B）→ ❗ 待做。
  3. **容量 / 步数 / KL 覆盖**（层数 3 → 6、步数 ×2、KL 的 token 数 8 → 16 / 32）→ ❗ 待做。
  4. **holdout 副作用**：随遗忘集增大而加重（1B：0.184 → 0.094 → 0.058）→ 部分已有数据，机制未查清。
- 状态：基础数据 🔄（E8 重跑与 baseline lr 修正中）；原因 2、3 ❗。

## 5.5 NEAR-Act：多实体场景的方案
- **表 6（九格对照）**：每格给 NEAR-Act（已进入匹配点的最大系数）与 NEAR-Dist（最终配置）、最佳 baseline、LUNAR 的 Prob / mia / extraction / utility / retain 生成 / 白盒；匹配点列标记。**图 5**：mia 随系数 c 的变化（3B forget05 / 10：c8 → c14 为 0.965 → 0.501、0.954 → 0.491）。
- **要写的结论（措辞边界见下）**：(1) 对 LUNAR：无拒答（ud_bb 0 对 0.2–0.5）、utility / retain 生成更高；白盒相同（都 ≈ 1.0）。(2) 对 NEAR-Dist：大遗忘集上 mia / extraction / utility 更接近 retain，代价是白盒。(3) 对 baseline：多数 baseline 在 forget05 / 10 上没有匹配点。
- **原因分析**：NEAR-Act 不加逐样本概率目标，遗忘集的概率分布自然保持（每位作者 sd(log p) 0.45–0.64，接近 retain 的 0.6–0.7）；但作者间并不均匀（每位作者 AUC 0.00–0.98），匹配点是平均出来的——**如实写**。组合（NEAR-Act 初始化 + 邻居标定）的小实验见 `exp/` 的对话记录：预期只是在两端之间移动。
- 状态：3B ✅（c14）；1B、8B 的 forget05 / 10 需扫系数到匹配点 ❗；8B forget10 全无 ❗。

## 5.7 采样攻击者分析
- **表 9**：一致性之差（forget − holdout）、每题不同名字数、最常用名字占比、跨问题同名占比、leak@k，对 retain、NEAR-Act、NEAR-Dist（早期 / 最终）、LUNAR、RMU。
- **叙述**：机制（51% 的替代名字来自训练邻居、同一问题混合 ~3 个邻居）→ 修正（标定 + 每题 3 个邻居 + 名字屏蔽）→ 验证（跨问题同名占比 0.30 → 0.15，概率宽度恢复）；**整体一致性之差（−0.11 到 −0.15）未解决，所有遗忘方法共有（RMU −0.10）**，作为局限。
- 状态：1B forget01 ✅，3B forget01 ✅，1B forget05 ✅；8B ❗（选做）。

## 措辞边界（与数据一致）
**可以写**：(1) 黑盒上两个 NEAR 方法都无痕迹，LUNAR 有明显拒答；(2) 白盒上 NEAR-Dist 比 NEAR-Act、LUNAR 小一个数量级；(3) 小遗忘集上 NEAR-Dist 对 1B、3B 的 baseline 保持更好；(4) 大遗忘集上 NEAR-Act（3B）的 mia / extraction / utility 更接近 retain；(5) 校准形状、名字蒸馏与邻居混合是 NEAR-Dist 痕迹的机制，修正后部分缓解。
**不能写**：NEAR-Dist “全面优于 baseline”（8B forget01 持平）；NEAR-Act “在所有规模上更好”（1B、8B 的大遗忘集还没到匹配点）；NEAR-Dist 与 retain “无法区分”（采样一致性）；因为发现了 NEAR-Dist 的局限所以提出 NEAR-Act（开发史相反）。
