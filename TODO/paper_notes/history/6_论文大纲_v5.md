## 1. 写作思路

### 1.1 一句话
遗忘后的模型对被遗忘实体的特殊对待，会暴露是谁被遗忘了（target leakage）。我们先**揭示**它：用以 retain 模型为参照的分层审计和两个攻击，说明每个现有方法都会在某一层被抓到，而且"回答看起来自然"并不等于"与对陌生人的回答不可区分"。再**降低**它：NEAR 把被遗忘实体锚定到属性匹配、模型从未见过的虚构邻居上，并且锚在输出分布上，而不是激活上。

### 1.2 两个核心对照

**对照一：自然 ≠ 不可区分**（Exposing 的核心，§5）
| 类别 | 方法 | 单条回答 | 被哪一层抓到 |
|---|---|---|---|
| 不自然 | LUNAR（拒答）、RMU（退化） | 拒答、乱码 | L1 拒答、L2 退化、A1、白盒 |
| 自然，但可区分 | ROCR（换成名人）、MEOW-nb（邻居答案的微调）、MEOW（反转事实） | 流畅 | ROCR：采样、A1、有监督白盒；MEOW-nb：采样、A1；MEOW：似然（mia 0.78–0.81） |
| 自然，大部分层面接近 retain | NEAR | 流畅 | 残留：采样（v2 待测）、编辑层之前的"残留认识"（白盒，方法无关） |
- 【已有】MEOW 论文自己的两种自然度攻击（PPL、一致性）对所有方法几乎都是 0：它们只看单条回答。

**对照二：痕迹来自"锚在哪里"，不是"目标是什么"**（Reducing 的机制，§6.3、§7.4）
| | 目标：拒答 | 目标：真实名人 | 目标：邻居 |
|---|---|---|---|
| **锚在激活上** | LUNAR：`wb_unsup` 0.69 | ROCR→邻居（放大残差）：0.66–0.91 | LUNAR 换邻居目标 0.80；NEAR-Act 0.98 |
| **锚在输出分布上** | **【待做】KL 目标换成"我不知道"** | MEOW 类：0.07–0.38 | NEAR：≈ 0.01–0.03 |
- 横看（同一锚，换目标）：白盒痕迹还在；竖看（同一目标，换锚）：痕迹消失。
- 同时，**目标决定黑盒痕迹**：LUNAR `ud_bb` 0.48–0.52 → 换邻居目标 0.00–0.03（阶梯消融）；ROCR 的 "Trump" 72–95% → 换邻居 0%。
- 空着的那一格是最便宜、信息量最大的待做实验（§8 X2）。

### 1.3 叙述顺序
按逻辑顺序写，不断言与事实相反的开发史（`0_命名对照.md`）：先给出 NEAR 的统一想法（锚到邻居）和唯一的设计轴（锚放在哪），然后说明锚在激活上（NEAR-Act，最直接的实现，沿用 LUNAR 的流水线）为什么会留下白盒痕迹，再给出锚在输出分布上的 NEAR。这既是逻辑顺序，也是真实的研究顺序。

### 1.4 贡献（与标题的两半对应）
1. **揭示 target leakage**：以 retain 模型为参照定义它；分层审计（拒答、异常、似然、白盒、采样）与两个攻击（黑盒排序 A1、自适应影子探针 A2）；在 TOFU 三个规模上，每个现有方法都会泄露，而且没有单一检测器能全部抓到；看起来自然的回答仍可被区分。
2. **NEAR**：锚定到属性匹配的陌生邻居，在输出分布上匹配，用原模型校准原答案的似然（逐题、按邻居标定），并约束保留答案的分布；不需要 retain 模型，只改少数投影矩阵，无推理开销。
3. **机制**：受控对照（目标 × 锚的位置）说明，白盒痕迹来自在激活上锚定所需的大位移（过冲），黑盒痕迹来自目标的选择。

### 1.5 措辞规矩
- 不说 undetectable / invisible / indistinguishable（指方法时）；不说 first（"隐匿"这个概念 MEOW 已提出）。
- 结论直接下判断、短句；局限集中写一次。
- 每个攻击和审计结果都附 retain 对照与零线。

## 3. 各节内容

### §1 Introduction（1.5 页）
- P1 背景：LLM 遗忘的用途；实体级遗忘（删除与目标实体相关的全部知识）。
- P2 问题：target leakage。遗忘后的模型对被遗忘实体区别对待（TAS、FUMA 已能利用）；为什么"被认出来"本身就是危害。
- P3 现状：拒答与退化是显眼的；近期方法转向流畅的替代答案（MEOW、ROCR），但流畅 ≠ 与模型对陌生人的回答同分布。
- P4 主张：应像 retain 模型那样，把被遗忘实体当作陌生实体。
- P5 Exposing：分层审计 + 两个攻击；每个现有方法都泄露，没有单一检测器能抓全（一两个数字：ROCR 的 A1 0.96–0.98；LUNAR 的拒答 0.34–0.52）。
- P6 Reducing：NEAR 的想法；锚在哪里是关键；受控变体的过冲；NEAR 的结果（拒答 ≈ 0、白盒接近 retain、utility）。
- P7 贡献（§1.4 的三条）。

### §2 Background（0.5 页）
实体级遗忘与 TOFU（full / retain / holdout；forget01/05/10）；方法族：梯度类（GA、NPO）、表征类（RMU、LUNAR）、重定向与编辑（ROCR，基于 ROME / AlphaEdit 式秩一编辑）、反事实替代（WHP、AltPO、MEOW）；模型对陌生实体倾向编造，采样一致性可以检测编造。

### §3 Target Leakage: Threat Model and Goal（0.75 页）
- 三方：provider、data subject、adversary；秘密是"谁被遗忘"。
- 攻击者知识：候选名单、保留实体上的行为（同 TAS）；没有遗忘集、原模型、标签。
- 能力：A1 文本（含重复采样）、A2 似然 / logits、A3 白盒、A4 自适应（知道算法与超参，不知道邻居）。主威胁模型是黑盒，白盒是扩展（`0_命名对照.md`）。
- **定义**：对某一层观察，target leakage = 该层上 forget 与陌生实体可区分的程度，相对 retain 模型的超出量；主指标是作者级识别（AUC，刀切法区间，置换零线）。
- 范围：不防持有原模型者；不讨论重学习；虚构实体。

### §4 Measuring Target Leakage（1.25 页）
- 4.1 审计五层：L1 拒答（复现 TAS 打分器）、L2 异常（退化、近重复、长度）、L3 似然（mia、遗忘/陌生答案概率比）、L4 白盒（无监督、有监督；最佳层 + 固定层）、L5 采样（一致性、不同名字数、最常用名字占比、跨问题同名）。
- 4.2 **A1 黑盒排序攻击**：模板由保留数据派生；候选池少数派设计（2 F + 20 H，45 池）；特征 L1+L2+L5（主攻击，事先固定），L6 logits 版本；池内稳健 z 分数、双向取最大；对照 retain 与 full。
- 4.3 **A2 影子探针攻击**：影子遗忘集 S = 作者 181–190（5 组 × 2）；在 M' 上执行同一算法与 provider 的选点规则；统一模板只换名字；P1 / P2 探针（逻辑回归 + 类均值之差；MLP 为敏感性）；选层规则只看影子数据（`post_edit_mean` 为主，`pre_edit_mean` 测残留认识）；名字长度控制；目标池 Q1（F 对陌生）/ Q2（F 对保留作者）；对照 retain。
- 4.4 选点规则与统计：匹配点 = Prob ≤ 0.25 中 utility 最高；mia 只报告；单种子的格子标明；1B 的攻击结果放附录（retain 对照落在零线上）。

### §5 Exposing Target Leakage in Existing Methods（1.5 页）
- Fig. 3 盲区地图（GA、NPO、RMU、LUNAR、ROCR、MEOW、MEOW-nb；GradDiff、SimNPO 进附录）。
- 5.1 不自然的痕迹：LUNAR 拒答（`ud_bb` 0.34–0.52）；RMU 退化（0.33–0.66）。
- 5.2 **自然 ≠ 不可区分**：MEOW 论文的自然度攻击对所有方法 ≈ 0；但 ROCR 的 "Trump" 72–95%、最常用名字占比 0.59–0.73，A1 0.96–0.98；MEOW-nb A1 0.93、采样 0.98–0.99；MEOW 的 mia 0.78–0.81（retain 0.36）。
- 5.3 白盒：有监督探针抓到 RMU 0.96、ROCR 0.86、LUNAR 0.72；**A2 在现有方法上的结果【待做】**。
- 5.4 梯度类（GA / NPO）：池内攻击看不到，因为损伤是全局的（陌生作者上同样不稳定）；它们的痕迹在有监督白盒（约 0.5–0.6，**种子 0 偏高的问题待查**）、似然与 utility 崩溃；只有崩掉的匹配点的格子如实写。
- 小结：没有单一检测器能抓全；每个方法死在不同的层。

### §6 NEAR（1.75 页）
- 6.1 **想法**：把被遗忘实体锚定到属性匹配、模型从未见过的虚构邻居。为什么是邻居：模型对邻居的行为 = 对同类陌生人的行为；四个反例：拒答区域（LUNAR）、随机方向（RMU）、知名真实人物（ROCR）、方法选定的固定替代答案（MEOW）。为什么要属性匹配：名字带着国籍、体裁等，"错误的陌生人"也是异常。
- 6.2 **邻居**：每位作者 15 位 GPT 生成的邻居，20 条一一平行的问答（`source_question` 校验）；10 位训练、5 位留作评测；邻居是 provider 的私有输入。
- 6.3 **锚放在哪里**：
  - 锚在激活上（NEAR-Act，简述）：每位作者的重定向向量 r = 邻居均值 − 遗忘均值；steering 选层；多层顺序回归 `W_down`。细节与阶梯消融进附录 B。
  - 诊断：r 只有激活范数的约 7%；c = 1 不改变回答；c ≥ 6 才有效，激活被推过邻居约 6 个 ‖r‖（过冲）；白盒随遗忘强度单调上升（0.53 → 0.99）；首词怪词。
  - 目标 × 锚的小表（§1.2 对照二），说明痕迹来自锚的位置。→ 所以锚在输出分布上。
- 6.4 **NEAR 的目标函数**（四项）：(a) 保留集激活约束；(b) 对邻居答案的 KL（前 8 个 token，每题固定 3 位邻居，屏蔽邻居名字）；(c) 逐题的原答案似然校准（按邻居标定，缩放到原模型在陌生作者上的平均水平）；(d) 保留答案的分布 KL。每一项对应它要约束的那个可观察量。
- 6.5 **参数化与成本**：只训练 3 层 `W_down`，从原权重开始，端到端；不需要 r 与 steering；推理零开销；不需要 retain 模型（写明 (c) 用了原模型在 holdout 作者答案上的**平均**概率，与评测共用 holdout）。
- 6.6 与反事实族的关系：WHP、Revisiting WHP、AltPO、MEOW、KARU 都是"换一个答案 / 实体"；NEAR 的区别在于参照是模型自己对陌生人的分布，并且以可检测性来评估。

### §7 Evaluating NEAR（3.25 页）
- 7.1 设置：三个规模 × forget01/05/10；基线（GA、NPO、RMU、LUNAR、ROCR、MEOW；GradDiff、SimNPO 附录）；NEAR-Act 作为受控变体。

### §8 Discussion and Limitations（0.5 页）
- **编辑层之前的残留认识**：只编辑中间层的方法（包括 NEAR）都不改变编辑层之前的激活，被遗忘实体在这些层上仍被"认识"；这一信号与算法无关，攻击者不需要知道算法。如何解读待 `pre_edit_mean` + 长度控制的结果（见 §8 风险 R4）。
- 采样残留（若 v2 仍有）。
- 编造不是目标；对真实人物，编造本身有害；参照应是模型对陌生人的行为（包括弃答）。
- 邻居依赖 GPT 生成；需保密；数据审计与错配邻居。
- 只在 TOFU（虚构、微调植入的实体，比预训练实体更容易遗忘——Ma et al.）与一个模型家族上。
