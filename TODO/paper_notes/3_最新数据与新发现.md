4. **属性匹配也有作用，但比"逐实体"弱**：错配邻居比 v2 高 +0.09 / +0.05 / +0.14（1B / 3B / 8B），1B 和 8B 都低于共享邻居。8B 的 +0.14 处在 8B 种子波动的边缘。黑盒和似然没有变差（8B 的概率比 1.33 → 1.22），utility 略低（−0.01 到 −0.02）。

## 8. 对故事线的影响【我的判断】
1. **NEAR-Dist v2 有望成为"所有通道上都接近 retain"的主方法**：拒答、似然、无监督白盒都接近 retain，utility 与 retain 模型相当；代价是有监督白盒 0.28（与 GA / NPO 同档）。这取决于其余 8 格能否复现。
2. **NEAR-Act 的定位**：激活版本，utility 高、黑盒干净，但白盒和 logits 都能识别，并且（初步看）指纹能从影子迁移。它说明"锚落在激活上"会留下痕迹，从而引出 NEAR-Dist。
3. **"自然 ≠ 不可区分"**：ROCR、MEOW-nb、NEAR-Act 三个例子已经够用，MEOW 本身提供似然通道上的例子。
4. **新的、需要正面写的局限**：所有只编辑中间层的方法（包括 NEAR 的两个版本）都保留了编辑层之前的"认识"。要写清楚：它说明"被遗忘的实体仍被模型识别为已知实体"，但这个信号不依赖于任何遗忘算法，攻击者不需要知道算法。
5. 论文的写法应是"分层评测 + 每个方法死在哪个通道"，而不是单一指标的排名。
6. **（11-14 新增）白盒痕迹的两个来源**：激活锚的过冲（确定），以及所有实体共享同一个目标（1B / 8B 支持、3B 弱，单种子，§2.4）。逐实体、属性匹配的邻居目标在有监督白盒上最低；属性匹配的贡献小于"逐实体"。
