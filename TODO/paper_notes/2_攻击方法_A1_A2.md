# 2 攻击方法：A1 黑盒排序攻击与 A2 影子探针攻击（2026-11-13）

> 本文写攻击的威胁模型、实现和细节；结果见 `3_最新数据与新发现.md`。A2 的原始规格（导师给的）见 `TODO/exp/A2_SPEC.md`，偏离记录在其 §9；命令见 `TODO/exp/19_*`、`21_*`。

## 0. 共同部分

### 0.1 要回答的问题
"遗忘质量"类指标衡量的是模型**还记不记得**被遗忘的事实。攻击问的是另一件事：**一个对手能否从遗忘后的模型 M' 中把被遗忘的实体认出来**，也就是 M' 与 retain 模型是否在实体层面可区分。

### 0.2 作者集合（A1 与 A2 共用的约定）
- **F**：被遗忘作者，forget05 的 10 位（作者 191–200）。主设置是 forget05：forget01 只有 2 位，组不成池。
- **H**：陌生作者，TOFU holdout05 ∪ holdout10 去重后的 20 位真实 holdout 作者，任何模型都没训练过他们。
- 作者名由程序从问题文本里提取（`rank_attack.extract_names` → `METHOD/ROCR/rocr.forget_author_names`：每 20 条问题里出现频率最高的最长名字，去掉所有格）。
- **候选池**：被遗忘作者**占少数**（每池 k = 2 位 F + 全部陌生作者）；10 位 F 的所有 2 人组合（45 个池）各算一次，取平均。
  - 【已验证】v1 的平衡池（10 : 10）不可用：池里一半是偏移的样本时，中位数 / MAD 标准化失去方向（8B LUNAR：L1+L2 0.92，加上 L5 变成 0.24）。

### 0.3 统计口径（A1 v2 与 A2 一致）
- **主统计量**：45 个池的平均 AUC（被遗忘作者的分数高于陌生作者的概率）。
- **区间**：删一作者刀切法的 95% 区间（作者才是独立单位，池不是）。
- **零线**：把 F / H 标签在作者间随机置换 200 次，取同一统计量的 95 分位数（`null95`）。**AUC 超过 null95 才算识别成功**。
- 另报 precision@|F|、MRR、平衡池 AUC。
- **方向**：A1 的打分是双向的（取 |z|）；A2 的探针分数有方向（越大越像"被遗忘"），所以 A2 用自己的有向版本（`spa.evaluate_transfer`；`rank_attack_v2.evaluate` 取 |z|，不能直接用于 A2）。
- 平局：随机打破（固定种子，300 次平均；没有平局时只算一次）。【已验证】v1 用稳定排序时，被遗忘作者在列表前面会赢下所有平局，precision@|F| 与 MRR 被虚高到 1.00。

### 0.4 对照
- **retain 模型（校准）**：F 与 H 对它都是陌生人，理想值约 0.5；它偏离 0.5 说明流程本身有偏差（名字风格、长度等）。
- **full 模型（阳性对照）**：认识 F、不认识 H，攻击应当能分开；分不开说明攻击对"认识与否"不敏感。

## 1. A1：黑盒重复查询排序攻击（`scripts/analysis/rank_attack_v2.py`）

### 1.1 威胁模型
攻击者只能**查询** M'（可以采样多次；L6 版本假设还能看到输出的 logits），手里有一份候选名单（含被遗忘者与陌生人），不知道谁被遗忘了，没有任何标签，也没有参照模型。目标：把候选按"像被遗忘"排序。

### 1.2 查询
- **模板**：从 retain95 的问句里派生（`templates_from_qa`）：把保留作者问题里的作者名换成 `{name}`，统计"有多少位作者用过这个句式"，取最常用的 10 个（至少 2 位作者用过）。实际用到的被 18 / 18 / 15 / 13 / 11 / 9 / 9 / 8 / 7 / 7 位保留作者共用，例如 "When was {name} born?"、"What are the professions of {name}'s parents?"、"What genre does {name} specialize in?"（`saves/analysis/rank_attack2_templates/templates.json`）。
  - 只用了保留数据，不含被遗忘作者的任何信息；与 TOFU 的问法一致，所以阳性对照比 v1（手写模板）有效。
- 每个（候选, 模板）：1 次贪心解码 + 10 次温度 1 采样，最多 64 个新 token；提示用 chat 模板（`sample_consistency.build_prompts`，系统提示 "You are a helpful assistant."）。

### 1.3 特征（每位候选一个向量，不用标签）
| 组 | 特征 | 含义 |
|---|---|---|
| L1 拒答 | `tas_refusal` | 所有回答的 TAS 式拒答分数均值（正则） |
| L2 退化 | `degenerate`、`dup`、`words` | 退化回答比例（重复 n-gram）、贪心回答之间近重复的比例、贪心回答的平均词数 |
| L5 采样一致性 | `self_agreement` | 同一问题的 10 个采样两两 ROUGE-L F1 的平均 |
| | `distinct_names` | 采样回答里替换掉的"另一个名字"有几个不同的 |
| | `modal_name_share` | 最常出现的那个替换名字占采样的比例 |
| | `cross_question_name_share` | 同一个替换名字在多少个不同问题里出现（占问题数的比例） |
| L6 logits | `greedy_logprob`、`greedy_entropy`、`logprob_sd` | 贪心回答的平均 token 对数概率、平均熵、对数概率在模板间的标准差 |

### 1.4 打分与攻击集合
- 每个池内，每个特征做稳健标准化（中位数 / 1.4826·MAD，下限 0.1·标准差），候选的分数 = 所用特征中 |z| 的**最大值**（双向异常分数）。
- **主攻击事先固定为 L1+L2+L5**；L1+L2、L5、L6、L1+L2+L5+L6 作为敏感性分析。单特征 AUC 只作信息展示（挑最好的那个特征用了标签，不是攻击）。

### 1.5 被攻击的模型
各方法 forget05 的匹配点：retain95、full、NEAR-Act、NEAR-Dist（目前是 **v1**）、LUNAR、ROCR 原版、GA、NPO、RMU（重训保留检查点：1B GA lr 2e-5 第 14 步 / NPO 2e-5 第 35 步 / RMU 5e-5 第 28 步；3B GA 第 21 步 / NPO 第 14 步 / RMU 1e-4 第 14 步；8B GA 第 14 步 / NPO 第 35 步 / RMU 1e-4 第 14 步），以及 1B / 3B 的 MEOW、MEOW-nb。链：`a1v2_lane.sh`、`a1v2_baselines_lane.sh`、`a1v2_meow_lane.sh`。

### 1.6 自然度攻击（MEOW 论文的两种，`scripts/analysis/naturalness.py`）
- **PPL 攻击**：在 retain 模型下"问题 + 回答"的困惑度 > 200 就判为"被遗忘"（针对乱码）。
- **一致性攻击**：MEOW 论文用"与 'Sorry, I don't know' 的嵌入相似度 > 0.2"；我们没有嵌入模型时改用 TAS 拒答分数 ≥ 0.5（同类检测器，已在输出里注明）。
- 报告 ASR（遗忘回答被标记的比例）与 FPR（holdout 回答被标记的比例）。

### 1.7 A1 的已知局限【我的判断】
1. **池内比较看不到全局损伤**：GA / NPO 让整个模型都不稳定（陌生作者也受影响），在"同一模型里 F 与 H 的差"里不显现。A1 的低分不等于"与 retain 不可区分"。
2. **1B 不可靠**：1B 的 retain 对照（0.69）就落在零线（0.68）上，名字分布本身带来差异。
3. **区间宽**：2 + 20 位作者，刀切法下限常低于零线。
4. **事先固定的主攻击不一定是每个模型最灵敏的版本**（最大值聚合会被噪声特征抬高），这是避免挑选偏差的代价。

## 2. A2：影子探针攻击（`scripts/analysis/spa.py`，链 `scripts/exp/spa_lib.sh`、`spa_lane_{1b,3b,8b}_act.sh`、`a2_p0_lane.sh`）

### 2.1 威胁模型（与规格一致）
| 攻击者有 | 攻击者没有 |
|---|---|
| M' 的权重（可以前向、取激活） | 原模型 M0、retain 模型 |
| 保留数据（知道哪些作者仍在模型里） | provider 的遗忘集 F |
| 遗忘算法及其超参数（含编辑层、选点规则） | provider 的邻居、随机种子 |
| 生成虚构名字 / 邻居的能力 | 任何关于目标候选的标签 |

思路：攻击者用**自己的影子遗忘集**在 M' 上再遗忘一次，从这些影子模型上学到"被这个算法遗忘过"的指纹，再用到 M' 上识别真正被遗忘的人。

### 2.2 作者集合（`spa.py sets` → `saves/analysis/spa/sets_v2.json`）
| 集合 | 来源 | 用途 |
|---|---|---|
| **S**（影子遗忘集） | 作者 181–190，5 组 × 2 人（组 k = 作者 181+2k、182+2k = forget10 的第 40k–40k+39 行） | 影子遗忘的正例 |
| **H_A** / **H_B** | 20 位真实 holdout 作者按种子打乱后各 10 位，不重叠 | 影子训练的负例 / 目标池的陌生人 |
| **R_A** / **R_B** | retain90（作者 1–180）中按种子抽 10 + 10 位**保留作者** | 指纹探针的负例 / 目标池的已知作者 |
| **F** | forget05 的 10 位 | 目标池的正例 |
- S 固定为 181–190（不是随机选）：只有作者 181–200 有邻居数据和 MEOW 的相反事实，forget05 下属于保留集的只有 181–190。
- 不用自造名字：20 位真实 holdout 作者足够，避免"真实 vs 自造名字"的风格混淆。

### 2.3 影子遗忘（第 1 步）
- 每组单独做：在 **M'** 上对 S_k 跑**同一算法**，得到 M''_k（k = 0…4）。对照条件把 M' 换成 retain95 模型（retain 上同样做 5 次影子遗忘）。
- NEAR 的影子编辑复用正式流水线（`single_run.sh` 的第 1–3 阶段），只用配置覆盖：
  - 遗忘行 `data.forget.dataset.args.hf_args.split="train[40k:40k+40]"`（forget10）、`basic.author_offset=181+2k`；
  - 邻居只取 S_k 自己的 train 邻居（`row_filter.author_id=[…]`，K = 5，与 provider 同一流水线）；heldout 邻居留给评测；
  - 保留集 retain90；层与 provider 相同。
- **影子强度：在影子上执行 provider 的选点规则**（NEAR-Act）：系数从弱到强试（3B：4 6 8 10 12 14 16；1B / 8B：2 3 4 5 6 7 9 11），取第一个使 S_k 的答案概率 ≤ 0.25 的系数（只用攻击者自己有的 S 的答案；读编辑流水线写出的 `responses_after_summary.json`）。
  - 【已验证】必须这样做：provider 的系数 c14 在 M' 上严重过冲（3B 第 0 组：S_k 0.781 → 0.008，陌生作者 0.13），新规则选中 c8 后 S_k = 0.177，正好等于 provider 在 M' 上对 F 的 0.177。各组选中的系数：3B real c4–c10、retain c10–c14；1B real c3–c6、retain c6–c11；8B real c5–c7、retain c6–c9（`saves/analysis/spa/shadow_strength_*.tsv`）。
  - NEAR-Dist 不扫系数（它有自己的标定），目前暂停，等 v2 的 M' 出来后再做。
- 编辑后的模型取完激活就删除（`KEEP_EDITED=1` 可保留，3B 每个约 6 GB）。

### 2.4 激活（第 2 步，`spa.py collect`）
- 所有名字（S、F、H_A、H_B、R_A、R_B，共 60 位）× A1 的 10 个模板，问题内容完全相同，只换名字。
- 取**每一层**的 block 输出在**提示最后一个 token**（chat 模板的助手开头之后）上的值，存成 float16 的 `.npz`（不上传）。规格要求的是 eoi 若干位置的平均，这里取最后一个 token（偏离已记录）。
- 同时记录每位作者真实答案的几何平均 token 概率（代理值，用于影子强度诊断）和名字的 token 数。

### 2.5 探针（第 3 步）
三个探针，逐层训练：
| 探针 | 训练数据 | 能学到什么 |
|---|---|---|
| **P0 认识性基线**（非自适应，不用影子） | 目标 M' 本身：R_A（认识）= 1，H_A（陌生）= 0 | 只能学"这个实体被模型认识" |
| **P1 规格版** | 影子 M''_k：S_k = 1，H_A = 0（5 个影子的样本合并） | 可以只学"认识 vs 陌生"，不一定学遗忘痕迹 |
| **P2 指纹版** | 影子 M''_k：S_k = 1；H_A + R_A + 别组的 S_j = 0 | 负例里也有"被认识但没被编辑"的作者，所以只有"被编辑过"能分开两类 |
- 分类器：逻辑回归（L2，C = 0.01，类别平衡）与类均值之差（无参数）；标准化只在训练数据上拟合。MLP 已实现（`--kinds mlp`），只作敏感性分析。
- **交叉验证**（只用训练数据）：P1 / P2 按影子模型分组留一（折 k：S_k、2 位 H_A（P2 再加 2 位 R_A）留出，在模型 k 上打分）；P0 在目标模型上按 R_A / H_A 分 5 折。

### 2.6 选层规则（第 4 步，`TODO/exp/21`；都不看目标标签）
| 规则 | 用哪些层 |
|---|---|
| `cv` | 交叉验证最高的层，并列取第一个（原规则，保留作敏感性分析） |
| `cv_deepest` | 交叉验证与最大值相差 ≤ 0.005 的层里最深的一层 |
| `post_edit_mean` | 最后一个编辑层之后的全部层：每层探针的分数先用它在自己训练数据上的均值和标准差标准化，再取平均（**编辑痕迹**） |
| `pre_edit_mean` | 第一个编辑层之前的全部层，做法同上（这些层上 M' = 原模型，测的是**残留认识**，不是编辑痕迹） |
- 攻击者知道编辑层（它们是算法的超参数），按编辑层划分层段不算用标签。
- 没有编辑层的方法（GA、NPO、RMU、MEOW）只有 `cv` 和 `cv_deepest`。
- 【已验证】为什么要改：NEAR-Act 的影子交叉验证从第一个编辑层起全是 1.00，`cv` 取了第一个，正好落在紧挨编辑层的"低谷"（迁移 AUC 0.3–0.6）；下游的层上信号很强。

### 2.7 名字长度控制
对每个规则得到的作者分数，在全部候选作者（F、H_B、R_B）上对名字 token 数做一次最小二乘（截距 + 斜率），用残差再评估。不分组、不用标签。原分数和修正后的分数都报告。
- 【已验证】为什么要做：P0 的分数与名字 token 数的 Spearman 相关为 −0.6 到 −0.78；retain 模型（不认识 F）上 P0 的 Q1 也有 0.62–0.84。
- 【我的判断】这个修正偏保守：若 F 的名字恰好系统性地更短，回归会连带去掉一部分真信号。

### 2.8 迁移与评估（第 5 步）
- 两个目标池：**Q1 = F 对 H_B**（M' 与 retain 是否可区分，包含残留认识）；**Q2 = F 对 R_B**（能否从已知作者里挑出被删的人，检验算法指纹）。
- 统计口径见 §0.3。另报：问题级 AUC、事后最佳层（用了目标标签，只是上界）、"影子模型里 F 对 H_B 的 AUC"（二次编辑检查）、分数与名字长度的 Spearman 相关。
- **结果怎么读（事先约定）**：主结果是 `post_edit_mean`（编辑痕迹）与 `pre_edit_mean`（残留认识）长度修正后的数；只有当 real 超过零线、并且明显高于同规则下的 retain 对照时，才算识别成功。

### 2.9 A2 的已知局限【我的判断】
1. 样本少：正例 10 位、负例 10 位作者，每位 10 个模板；作者级区间宽。
2. 影子与目标的规模不同（2 人对 10 人），影子强度靠选点规则对齐，不能保证指纹完全一样。
3. 只覆盖线性探针（加一个 MLP 敏感性分析）和"提示最后一个 token"这一个位置。
4. 目前只做了 NEAR-Act（三个规模）；LUNAR、ROCR、RMU、GA、NPO、MEOW 的影子编辑还没写，NEAR-Dist 要等 v2。
5. S 固定为作者 181–190，S 与 F 都在 TOFU 的最后 20 位作者里；与 R（作者 1–180）相比，可能存在作者批次带来的系统差异（1B 上 Q2 在编辑层之前就有 0.84–0.90，这在原模型里本不该有，原因未查）。
