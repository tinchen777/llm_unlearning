## A. 正在跑：铰链（1B，`kl_layers/5_forget_prob.sh`）
```
FPS="1" bash scripts/NEAR/kl_layers/5_forget_prob.sh 0
FPS="3" bash scripts/NEAR/kl_layers/5_forget_prob.sh 1
```
4 个运行：层 11-12-13，c {1, 1.5}，铰链权重 {1, 3}，目标 0.17，KL=1。运行名 `rw1_ans_kl1_fp<μ>_increment_seq_c<c>_l11-12-13`。

**跑完看什么**
- 对照（同样 c、层，只有 KL，没有铰链）：c1：Prob 0.556、`wb_unsup` 0.568、retain 生成 0.754；c1.5：Prob 0.516、`wb_unsup` 0.913、retain 生成 0.746。
- 成功：Prob 降到 0.2 左右，而 `wb_unsup` 没有涨到 0.99（前沿被推动）；失败：Prob 降了但白盒也涨到 0.99，或出现乱码（看 `forget_responses.json` 的首词、`ud_bb`、retain ROUGE）。
- `w_down_summary.json` 的 `kl.history` 里的 `forget_prob` 应逐步靠近 0.17（不动则是权重 / 步数问题）。
- 读完后：写 `near_line/19`，并决定 1B 的最终配置（主配置 c7 l7-9，铰链 / KL 作为黑盒变体与否）。

## A2. 铰链：不依赖 retain 模型的目标 + 双向模式（1B，**新**，见 near_line/19）
上一批铰链的 τ=0.17 是 retain 模型的值（违反设定）且过冲（实际 0.08）。现在 τ 取原模型在 holdout 上的答案概率（`unseen`，约 0.16），并新增双向模式 `match`：
```
bash scripts/NEAR/kl_layers/7_forget_prob_target.sh 0                      # match 和 hinge，τ=unseen，c1，层 11-12-13
LAYER_SETS="9,10,11" bash scripts/NEAR/kl_layers/7_forget_prob_target.sh 1  # 浅一点的层
```
运行名 `rw1_ans_kl1_fp1_ftunseen_fm<模式>_increment_seq_c1_l<层>`。想要 Prob ≈ 0.16、mia ≈ 0.48、extraction ≈ 0.06、`wb_unsup` ≈ 0.5–0.6；训练日志里会打印 `forget_prob_target = ...`。注意：config 的默认 τ 已改成 `unseen`，重跑 `5_forget_prob.sh` 也会用它。

对入选点补 full 评测（含释义 / 扰动问题的 Prob，检查泛化；覆盖原来的 fast 评测目录，full 是 fast 的超集）：
```
SELECT_TASK_NAME=single_v2/near_tofu_Llama-3.2-1B-Instruct_forget01_ks \
TASK_NAME=single_v2/rw1_ans_kl1_fp1_increment_seq_c1_l11-12-13 K=5 COEFF=1 MODE=all W_DOWN_LAYER="[11,12,13]" \
bash scripts/NEAR/single_run.sh <GPU> "4"
```

## A5. 3B / 8B 上新旧方法的验证（决定基调；全部完整评测 `EVAL_PROFILE=full`，自带开销数据）
**旧方法 = steering**（`Llama3B_v2` / `Llama8B_v2`），**新方法 = KL + 铰链，无 steering**（`Llama3B_v3` / `Llama8B_v3`，上游仍在 v2）。选层结果：3B：c8→14、c10→14；8B：c6→17、c7→19（gap 0.30，退化 0.07）、c8→16。

```

# 3B 新方法：两个层位置
OUT_PREFIX=Llama3B_v3 UPSTREAM_PREFIX=Llama3B_v2 MODEL=Llama-3.2-3B-Instruct EXTRA_WDOWN="wdown.kl.fr_batch_size=16" \

for spec in "7:17,18,19" "6:15,16,17"; do
```
