# 17 小系数 + KL 在更深的层上的结果；KL 是否到了下限（1B，forget01）

## 问题
near_line/15 之后的两个疑问：
1. 小系数（c1、c1.5、c2）在更深的层（9-11、10-12、11-13）上加 KL，能否在小白盒痕迹下做到遗忘？
2. KL 训练是否到了下限（c2、l11-12，300 步）？

## 做法
`scripts/NEAR/kl_layers/`：0（c1、c1.5 的选层）、1–3（三个层集 × c {1, 1.5, 2} × KL {off, 1}，`EVAL_PROFILE=fast`）、4（c2、l11-12、KL=1、300 步）。`increment` + `sequential` + 答案 token，K=5。l10-11-12 的 c2 两个运行后来补跑完（Prob 0.727 → 0.499，`wb_unsup` 0.990 / 0.986），结论不变，整张网格完整。

## 结论
1. **小系数 + KL 仍没有做到 retain 水平**：最好的是 l11-13 c2 KL1（Prob 0.475、mia 0.931），离 0.17 / 0.48 很远。遗忘到位仍需要大偏移（c7），大偏移 `wb_unsup` ≈ 0.99。near_line/15 的结论不变。
2. **KL 的效果很稳定**：在每一个（层集、系数）上，加 KL 都把 Prob 降低约 0.25–0.3（如 l9-11 c1.5：0.858→0.585；l11-13 c2：0.745→0.475），utility 只少 0.01–0.02，retain ROUGE 少 0.05–0.1。深层（l11-13）的 retain 代价最小（0.815→0.754）。
3. **深层 + 小系数是比 l7-9 + 小系数更好的"小痕迹"操作点**：l11-13 c1 KL1 与 l7-9 c2 KL1 的 Prob 相同（0.556）、`wb_unsup` 相近（0.568 对 0.495），但 retain ROUGE 0.754 对 0.510，utility 0.572 对 0.556。这给出了一个 "小系数—小痕迹—中等遗忘" 的操作点，但遗忘只到 Prob 0.55。
4. **白盒痕迹由（系数, 层）决定，KL 基本不改变**：同样的 c 在更深的层上 `wb_unsup` 更大（c1 off：l9-11 0.095，l10-12 0.349，l11-13 0.433；c2 off：0.819、—、0.998）。KL 配置 ≥ off（l9-11 c1：0.095→0.533，因为 off 时什么都没做）。
5. **KL 没有"饱和"在 0.5 的硬下限**：300 步里 KL 继续降到约 0.39，但遗忘指标几乎不动（Prob 0.515→0.502、mia 0.942→0.940）。说明问题不是训练不足，而是 KL 项（邻居答案前 8 个 token）与评测（真实答案的概率）不是同一个量，再多训练也不会压低真实答案的概率。
6. Prob–`wb_unsup` 的前沿（1B，KL 后）：Prob 0.62 / 0.53（l9-11 c1），0.556 / 0.57（l11-13 c1），0.556 / 0.50（l7-9 c2），0.40 / 0.76（l7-9 c4 KL3），0.21 / 0.99（c7）。遗忘越强，痕迹越大，目前没有被打破的点。

## 注意
单次运行；层集固定；l10-12 c2 缺；KL 超参未调（100 步、lr 2e-5、λ=1，n_tokens=8）。

## 下一步
1. **停止小系数探索**，把它们作为"痕迹—遗忘"权衡曲线的一部分写进论文：NEAR 有一个旋钮（系数 + 层 + 是否 KL），从"几乎不遗忘、痕迹小"连续到"遗忘到 retain 水平、痕迹大"（上面 6 的前沿）。
2. 主结果配置定为 c7 l7-9（+KL 作为黑盒更自然的变体）；白盒痕迹作为局限如实写。
3. 若还想继续一件事：直接让 KL 项针对真实 forget 答案（压低真实答案的概率），而不是邻居答案前缀；这是唯一没有试过、可能改变 Prob–痕迹前沿的杠杆。时间紧可不做。
