# 10 降低 NEAR 的白盒痕迹；LUNAR 与 baseline 调参

## 问题

1. NEAR 黑盒隐蔽（`ud_bb` 0–0.08）但白盒痕迹很大（无监督离群 `ud_wb_unsup` 0.985–0.996，比 LUNAR forget01 的 0.57 还大）。
2. 对比不公平：LUNAR 只跑了默认设置（系数 2，遗忘整个 forget01 时 `model_utility` 掉到 0.27、对良性问题拒答 32%）；baseline 在 forget01 上基本没遗忘（40 条、每个 epoch 2 步、总共 20 步，lr 1e-5 太小，bf16 下更新还会被舍入吃掉一部分）。

## 做法

### 1 降低白盒痕迹（先做"小系数 + 更多层"，再考虑目标函数）

- 依据：B（3 层）与单层 A 的总位移相同（`7·r_9`），遗忘却强得多（`forget_Q_A_Prob` 0.16 对 0.46），说明**把位移分摊到更多层比加大系数更有效**；所以可能用更小的系数、更多的层达到同样的遗忘，并减小激活上的偏移。
- `scripts/NEAR/sweep_footprint.sh`：系数 {4, 5, 6} × 层集 {7–9, 6–9, 5–9}（`increment` + 顺序训练 + 答案 token，`retain_weight` 1），r_UV 和选层文件读 `${BASE}_ks`（K=5，系数 2/4/5/6/7/8/12 都在）；每个格子 = W_down 训练 + 一次完整评测。
- `summarize_sweep.py --pareto`：steering 扫描里（footprint，`unseen_gap`）的帕累托前沿。单层的前沿显示 `unseen_gap` 与 footprint 单调权衡：要 `unseen_gap` ≈ 0.31 需要 footprint ≈ 0.6（c7/L9），≈ 0.44 需要 0.49（c6/L8），≈ 0.64 需要 0.34（c4/L8–9）；多层在同样的 footprint 下遗忘更强，是这一步要验证的。
- **要小心的陷阱**：不能为了让我们的无监督探测（只看 eoi 位置的池化激活）失效而选特定设计（比如只给非 eoi 的 token 加位移），那只是对这个探测器过拟合。需要把探测器的位置扩宽（例如所有 prompt token 的均值）后再下结论。后续要做。
- 后续备选：(a) 每个样本取"刚好让回答改变的最小系数"，用异质系数训练；(b) 目标改为匹配干净分布（把 forget 的激活拉到 neighbor 或 retain 模型激活的分布内，而不是常数平移）。

### 2 公平性：LUNAR 和 baseline 调参

- `scripts/LUNAR/sweep_coeff.sh`：系数 {0.5, 1, 1.5}（可加 `LUNAR_unverified`）× forget01 / forget005；r_UV 只算一次，之后每个系数跑选层 + W_down + 与 NEAR 相同的评测（和已有的 c2 在同一个任务文件夹里，不覆盖）。
- `scripts/unlearn/tune.sh`：每个 baseline 方法的学习率（默认 5e-5、1e-4）和权重精度（`DTYPES="bf16 float32"`，fp32 是 fp32 主权重 + bf16 自动混合精度）；`PROBE=0` 只评 TOFU 指标，选定后再用 `PROBE=1` 重跑一次得到 UD。
- `scripts/analysis/baseline_table.py`：每个 baseline run 取"`model_utility` 不低于原模型 95% 的 checkpoint 里 `forget_quality` 最大的 epoch"（TOFU / OpenUnlearning 的协议），一张表看完。
- 目前（默认 lr、最后几个 epoch）：GradAscent / GradDiff / SimNPO / IdkDPO / RMU 的 `forget_Q_A_Prob` 0.6–0.9（retain 0.17），NPO 最好 0.34，均没有真正遗忘。
