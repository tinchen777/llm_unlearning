# 26 旧方法（NEAR-Steer）在 3B forget05 / forget10 上扫更大的系数（c8、c10、c12）

## 问题
`near_line/23` 之后：3B 的旧方法 c8 在 forget05 / forget10 上没遗忘到位（Prob 0.54–0.57）。要作为公平的基线，需要把系数加大到能遗忘。

## 做法
`sweep_select.sh`（c10、c12，窗口 [0.25, 0.75]，选层）+ `sweep_w_down.sh`（层＝选层及下面两层，`increment` + `sequential` + 答案 token，完整评测）。

## 结论
1. **系数加大后 Prob 单调下降**（forget05：0.567 → 0.401 → 0.267；forget10：0.543 → 0.386 → 0.264），c12 已接近匹配线（Prob ≤ 0.25 差一点），再加大（c14）大概率跨过去；到 c12 时仍未达到匹配点，需要如实写成“扫到 c12”或再补 c14。
2. **c12 的旧方法在大遗忘集上的保持与 mia 反而优于新方法**：forget05：mia 0.698 对 0.911，utility 0.607 对 0.551，retain 生成 0.704 对 0.675；forget10：mia 0.667 对 0.945，utility 0.634 对 0.521，retain 生成 0.729 对 0.707。代价是白盒（0.91 / 0.88，新方法 0.013 / 0.026）和更大的偏移。
3. 这支持“**两个方法的优势场景不同**”：大遗忘集上，旧方法 mia 与保持更好，新方法白盒隐蔽；小遗忘集（forget01）上新方法两项都不输。但新方法的 mia 偏高部分来自 match 的逐样本崩塌（`near_line/25`），修好以后对比可能变化，应该用修好后的版本重新对照。
