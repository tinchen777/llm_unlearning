# 15 KL 网格结果：小系数 + KL，以及 KL 在不同层位置上的效果（1B，forget01）

## 问题
1. 小系数（c2、c4）+ KL 能否在更小的白盒痕迹下做到遗忘？（near_line/13 的假设：把"行为"交给 KL，激活留在邻居附近。）
2. KL 的效果是否依赖离输出的距离（层 7-9 对 11-12）？
3. KL 权重 λ（1 对 3）和"只多训练一阶段、没有 KL 项"（kl0）各自的作用。

## 做法
`scripts/NEAR/sweep_kl.sh`：c ∈ {2, 4} × λ ∈ {off, 1, 3} × 层 7-9；补充 c2 × {off, 0, 1} × 层 11-12。均为 `increment` + `sequential` + 答案 token，层集固定（未按 c 重新选层）。

## 结论
1. **小系数 + KL 没有把遗忘做到 retain 水平**：所有 c2/c4 的配置 Prob ≥ 0.40、mia ≥ 0.92（retain 0.17 / 0.48），只有 c7 到了 retain 水平。遗忘到位仍需要大偏移，大偏移仍然 `wb_unsup` ≈ 0.99。白盒痕迹与遗忘强度同向的结论没有被 KL 打破。
2. **KL 把"痕迹–遗忘"的前沿推进了一点**：c4 上 KL 使 Prob 0.557→0.40、`wb_unsup` 0.848→0.76–0.78；c2（l7-9）Prob 0.805→0.55，但 `wb_unsup` 从 0.23 升到 0.50（c2 off 的低值只是因为什么都没做）。
3. **在 l7-9 上 KL 的 retain 代价很大**：retain ROUGE c2 0.792→0.51、c4 0.686→0.54（utility −0.04）；c7 上 0.588→0.551。λ=3 与 λ=1 几乎一样（Prob 0.543 对 0.556；c4 0.400 对 0.406）→ KL 项已经"饱和"，λ 不是瓶颈（步数 / lr 可能才是）。
4. **在 l11-12 上 KL 几乎没有 retain 代价**（retain ROUGE 0.812→0.788，utility 0.582→0.579），同时 Prob 0.741→0.515；`kl0`（只做端到端 MSE、没有 KL）与 off 相同（0.757 对 0.741）→ **变化来自 KL 项，不是多训练一阶段**。支持"KL 在离输出更近的层上更有效、更便宜"的假设（near_line/12 的担心）。但 l11-12 的 `wb_unsup` 0.98（r_UV 在深层更大，同样的 c 对应更大的 footprint；l7-9 的 c2 只有 0.23–0.5）。
5. 怪词：所有 KL 配置的 forget 回答首词都变成 "Ali / Mubarak / Pavel / The"（邻居式的另一位虚构作者），不再有 "Basil / Nikolai / Basis"；`ud_bb` 全为 0。

## 注意
- 单次运行；层集固定在 7-9 / 11-12，未按 c 重选；步数 100、lr 2e-5 是未调的默认。
- 比较"同遗忘强度下的 footprint"需要更多点；目前 KL 只在 c4 上给出一个同向的小改善。

## 下一步
1. 更强的 KL 优化：增加步数 / lr，λ 不必再加。看 c4（以及 c5）能否把 Prob 压到 0.2–0.25。
2. 试"更深的层 + 中等系数 + KL"：1B 的 c4 选层结果是第 13 层（深度 81%），从未训练过；c4/l11-13 + KL。
3. 回头看白盒来源：KL 不能让 `wb_unsup` 下降到可接受，这一项可能要靠训练目标（匹配 benign 分布）而不是行为约束。
