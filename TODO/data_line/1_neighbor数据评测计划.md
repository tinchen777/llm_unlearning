# 1 neighbor 数据本身的评测计划

## 问题

- neighbor 数据是用户用 GPT 自造的：每个被遗忘的作者构造 15 个**同属性**的作者邻居，每个邻居 20 条 QA（`data/tofu/tofu_neighbor{005,01,05,10}.csv`，不在仓库里）。
- 担心数据本身的问题影响遗忘效果；问：要不要对数据做评测，论文里是否需要展示。

## 结论（讨论）

**需要，论文里也应该展示。** 理由：

1. neighbor 数据在方法里是**承重**的，用在四处：
   - `r_UV[K][author]` = K 个邻居问题的平均激活 − 该作者 forget 问题的平均激活（重定向目标）；
   - 选层时，`unseen_gap` 把 forget 的行为向"陌生问题（neighbor / holdout）的行为"对齐；
   - W_down 的 retain 集合 = `[retain, neighbor]`（邻居的 token 保持原输出）；
   - 评测：`neighbor_responses`、探针 `forget | neighbor`、UD 的良性集合。
2. baseline 没有这份额外数据，审稿人会问：**是不是靠数据多拿到的优势？数据质量/泄漏/匹配程度是否影响结果？**
3. 数据是合成的，需要说明构造协议、统计、质量审计和敏感性，这是合成数据贡献的标准内容。

## 已有数据里的第一个信号（来自已保存的评测，1B full 模型）

| 集合 | 答案对数概率 | 答案概率 | 标准答案平均词数 |
|---|---|---|---|
| holdout（真实 TOFU 未见作者） | −2.14 | 0.161 | 27.0 |
| **neighbor（GPT 自造）** | **−3.02** | **0.082** | **23.5** |

两者对 full 模型都是"没见过"（ROUGE 0.39 对 0.38，行为一致），但 neighbor 的答案更不"像 TOFU"（更不可预测、更短）。可能是生成器/提示词的风格差异。要确认是数据属性而不是模型属性，需要对照 retain 模型在 neighbor 上的同一数字（retain 的评测在重跑）。

## 计划

### A. 数据审计（自动检查 + 小样本 LLM 评审）

| 检查 | 目的 | 做法 |
|---|---|---|
| 结构 | 每作者 15 个邻居、每邻居 20 条、无缺失 | 计数 |
| 重复 | 邻居之间 / 邻居与 TOFU 4000 条 / 与 forget 的精确与近重复 | 规范化文本 + n-gram Jaccard |
| 命名冲突 | 邻居名字与 TOFU 作者重名、邻居之间重名 | 名字集合比较 |
| **泄漏** | 邻居问答里是否出现 forget 作者的名字或其具体事实（出生地、作品、父母职业） | forget 作者姓名/关键词命中率；邻居答案与同类问题的 forget 答案的相似度 |
| 属性匹配 | "同属性"是否成立（国家、体裁、性别…） | 规则抽取（"born in …"、genre）的匹配率 + 约 100 条的 LLM 评审（给出提示词模板） |
| 风格偏移 | 与 TOFU 风格是否一致（长度、词汇、模板覆盖） | 长度分布；用文本特征训练"邻居 vs TOFU"分类器，AUC≈0.5 才说明风格一致 |
| 模型侧：是否"未见" | 邻居对 full/retain 模型是否像陌生数据 | full 与 retain 模型在 neighbor 与 holdout 上的 ROUGE、对数概率对照 |

### B. 数据敏感性消融（论文里真正说明问题的部分）

| 变体 | 回答的问题 | 成本 |
|---|---|---|
| 匹配邻居（现状） | 对照 | – |
| **错配邻居**：把作者 → 邻居的映射打乱 | 属性匹配是否必要 | 低：不用新数据，改映射 |
| **用 TOFU 的其他 retain 作者当邻居** | 不用 GPT 能不能行 | 低：不用新数据 |
| K = 1 / 5 / 15 | 需要多少邻居 | 低：`ruv.ks` 已支持 |
| **泄漏注入**：把 x% 的邻居 QA 换成 forget QA | 对数据污染的鲁棒性 | 中 |

### C. 公平性

- baseline 没用 neighbor 数据：加一个"同样用 neighbor 数据"的对照——例如 **LUNAR 的参考集换成 neighbor 问题**（全局平均）对比 NEAR 的**按作者**匹配，把"用了邻居数据"和"按作者属性匹配"的贡献分开。
- 论文里写明数据需求、生成成本，并公开生成提示词和数据。
